# Moving PolyglotFormFill to a new machine

The portable source zip (`PolyglotFormFill-source.zip`) contains exactly the git-tracked
source — no build artifacts (`node_modules/`, `target/`, `dist/`, guide video/audio outputs
are all regenerable and excluded).

## 1. Prerequisites

| Tool | Version | Notes |
|---|---|---|
| Node.js | >= 20 (`.nvmrc` pins the exact minor) | JS/TS packages |
| pnpm | 9.12.0 | `corepack enable` then `corepack prepare pnpm@9.12.0 --activate` (repo enforces pnpm via `only-allow`) |
| Rust / cargo | stable (edition 2021) | native core + Tauri app |
| Tauri v2 system deps | per OS | Windows: WebView2 + MSVC Build Tools; see tauri.app prerequisites |

## 2. Unpack

```
unzip PolyglotFormFill-source.zip -d PolyglotFormFill
cd PolyglotFormFill
cp .env.example .env   # then fill in any local values (no secrets are shipped in the zip)
```

## 3. Install dependencies

```
corepack enable
pnpm install          # installs the whole workspace (recursive)
```

The repo uses pnpm overrides that stub heavy native deps (`onnxruntime-node`, `sharp`,
`@napi-rs/canvas`) from `./stubs/`, plus a patched `@pdf-lib/fontkit` — these apply
automatically during `pnpm install`.

## 4. Build

```
pnpm build            # builds all workspace packages (tsc + vite for apps/app)
cargo build           # builds the Rust workspace (crates/* + apps/app/src-tauri)
```

Desktop app (Tauri) dev / bundle:

```
cd apps/app
pnpm dev              # vite dev server
pnpm tauri dev        # run the desktop app
pnpm tauri build      # produce the installer
```

## 5. Verify

```
pnpm test
pnpm typecheck
pnpm lint
node scripts/check-traceability.mjs
```

## Notes
- `cargo build` is slow on first run (large workspace); the `target/` it produces is
  regenerable and intentionally excluded from the zip.
- Guide/video assets under `docs/guide/output/` are regenerated by
  `node scripts/build-guide.mjs`; they are not in the zip.
