# IP Strategy — PolyglotFormFill

> Overview, not legal advice. Consult a qualified IP attorney. Owner: Subramanya Mysore (India).

The pragmatic, cost-aware IP stack for a solo-built, privacy-first software product sold globally.

## 1. Copyright (automatic, do now — free/cheap)
- Your code, UI, docs, and marketing are copyrighted the moment written.
- **Done:** proprietary `LICENSE` (all rights reserved) + this repo is private/proprietary.
- **To do:** optional formal registration (stronger enforcement/statutory damages, esp. US) — low cost.

## 2. Trademark (best value — do soon)
- Register **PolyglotFormFill** + logo (Classes 9 & 42). See `trademark.md`.
- Often the single most valuable, enforceable, affordable IP for a product brand.

## 3. Trade secrets (do now — process/discipline)
- Keep the **vendor private licensing key** (`vendor-key.json`) and any unpublished algorithms confidential.
- NDAs with any contractors/collaborators; least-privilege access.

## 4. Patents (assess — higher cost, uncertain for software)
- Candidate novel methods documented in `invention-disclosure.md` (Inventions 1–3).
- **India (§3(k))** rarely grants "computer programme per se" patents without a technical effect;
  **US** (post-*Alice*) is more permissive but rejects "abstract" claims.
- **Recommended first step:** a low-cost **US provisional** (~$65–300 filing) on Invention 1
  (form-shape-driven combine/split) to secure a priority date and "patent pending," then a 12-month
  window to decide on a full (expensive) filing after an attorney's prior-art search.

## 5. Defensive publication (fallback)
- If you decide *not* to patent a method, publishing a clear description establishes prior art so a
  competitor can't patent it against you.

## Recommended order of action
1. File the **trademark** (name + logo).
2. Keep the private key + methods as **trade secrets**; add NDAs.
3. 30-minute **patent attorney** consult on Invention 1 → decide on a **US provisional**.
4. Consider **copyright registration** if entering the US market.
