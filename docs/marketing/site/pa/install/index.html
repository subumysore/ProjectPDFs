ਐਕਸਟੈਂਸ਼ਨ ਡਾਊਨਲੋਡ ਕਰੋ (.zip)

ਜਦੋਂ ਤੱਕ ਇਹ ਸਟੋਰਾਂ 'ਤੇ ਨਹੀਂ ਆ ਜਾਂਦਾ, ਇਸਨੂੰ ਡਿਵੈਲਪਰ ਮੋਡ ਵਿੱਚ ਲੋਡ ਕਰੋ:

  1. ਡਾਊਨਲੋਡ ਨੂੰ ਇੱਕ ਫੋਲਡਰ ਵਿੱਚ ਅਨਜ਼ਿਪ ਕਰੋ।
  2. chrome://extensions (ਜਾਂ edge://extensions) ਖੋਲ੍ਹੋ।
  3. Developer mode ਚਾਲੂ ਕਰੋ (ਉੱਪਰ-ਸੱਜੇ)।
  4. Load unpacked 'ਤੇ ਕਲਿੱਕ ਕਰੋ → ਅਨਜ਼ਿਪ ਕੀਤਾ ਫੋਲਡਰ ਚੁਣੋ। PolyglotFormFill ਹੁਣ ਤੁਹਾਡੀ ਐਕਸਟੈਂਸ਼ਨ ਸੂਚੀ ਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।
  5. ਇਸਨੂੰ ਟੂਲਬਾਰ 'ਤੇ ਪਿੰਨ ਕਰੋ ਤਾਂ ਜੋ ਤੁਸੀਂ ਇਸਨੂੰ ਲੱਭ ਸਕੋ: ਬ੍ਰਾਊਜ਼ਰ ਦੇ ਉੱਪਰ-ਸੱਜੇ ਨੇੜੇ ਬੁਝਾਰਤ-ਟੁਕੜੇ ਦੇ ਆਈਕਨ 🧩 'ਤੇ ਕਲਿੱਕ ਕਰੋ (ਇਹ Extensions ਮੀਨੂ ਹੈ), PolyglotFormFill ਲੱਭੋ, ਅਤੇ ਇਸਦੇ ਕੋਲ ਪਿੰਨ 📌 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਇਸਦਾ ਆਈਕਨ ਹੁਣ ਤੁਹਾਡੇ ਟੂਲਬਾਰ 'ਤੇ ਰਹਿੰਦਾ ਹੈ।
  6. ਉਸ PolyglotFormFill ਟੂਲਬਾਰ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ → ਇੱਕ ਪਾਸਫ੍ਰੇਜ਼ ਸੈੱਟ ਕਰੋ (ਜਾਂ ਪਾਸਕੀ ਨਾਲ ਅਨਲੌਕ ਕਰੋ)।
  7. ਪੌਪਅੱਪ ਵਿੱਚ "Your details" ਦੇ ਹੇਠਾਂ, ਹਰ ਫੀਲਡ (ਜਿਵੇਂ full_name, email, phone) ਅਤੇ ਇਸਦਾ ਮੁੱਲ ਟਾਈਪ ਕਰੋ, ਫਿਰ Save field ਕਰੋ। ਇਹ ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਉੱਤੇ ਐਨਕ੍ਰਿਪਟਿਡ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ। ਫਿਰ ਇੱਕ ਫਾਰਮ ਖੋਲ੍ਹੋ ਅਤੇ Fill this page 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਲੋਡ ਕਰਨ ਤੋਂ ਤੁਰੰਤ ਬਾਅਦ ਟੂਲਬਾਰ ਆਈਕਨ ਨਹੀਂ ਦਿਸਦਾ? ਇਹ ਆਮ ਹੈ — Chrome ਨਵੇਂ ਐਕਸਟੈਂਸ਼ਨਾਂ ਨੂੰ 🧩 ਬੁਝਾਰਤ-ਟੁਕੜੇ ਦੇ ਮੀਨੂ ਪਿੱਛੇ ਉਦੋਂ ਤੱਕ ਲੁਕਾਉਂਦਾ ਹੈ ਜਦੋਂ ਤੱਕ ਤੁਸੀਂ ਉਹਨਾਂ ਨੂੰ ਪਿੰਨ ਨਹੀਂ ਕਰਦੇ (ਕਦਮ 5)। Firefox: about:debugging → "Load Temporary Add-on" ਵਰਤੋ, ਫਿਰ ਟੂਲਬਾਰ ਓਵਰਫਲੋ ਤੋਂ ਪਿੰਨ ਕਰੋ।
