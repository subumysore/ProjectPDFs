🧩 תוסף דפדפן v1.0.3

הורדת התוסף (.zip)

עד שהוא יגיע לחנויות, טענו אותו במצב מפתחים:

  1. חלצו את ההורדה לתיקייה.
  2. פתחו את chrome://extensions (או edge://extensions).
  3. הפעילו את מצב מפתחים (בפינה הימנית העליונה).
  4. לחצו על Load unpacked ← בחרו את התיקייה שחילצתם. ‏PolyglotFormFill מופיע כעת ברשימת התוספים שלכם.
  5. נעצו אותו לסרגל הכלים כדי שתוכלו למצוא אותו: לחצו על סמל חלק הפאזל 🧩 ליד הפינה הימנית העליונה של הדפדפן (זהו תפריט התוספים), מצאו את PolyglotFormFill, ולחצו על נעץ 📌 שלצידו. הסמל שלו יופיע כעת בסרגל הכלים שלכם.
  6. לחצו על סמל PolyglotFormFill בסרגל הכלים ← הגדירו ביטוי סיסמה (או פתחו במפתח גישה).
  7. תחת «הפרטים שלכם» בחלון הקופץ, הקלידו כל שדה (למשל full_name, email, phone) ואת ערכו, ואז Save field. אלה נשמרים מוצפנים על המכשיר שלכם. לאחר מכן פתחו טופס ולחצו על Fill this page.

לא רואים סמל בסרגל הכלים מיד לאחר הטעינה? זה נורמלי — Chrome מסתיר תוספים חדשים מאחורי תפריט חלק הפאזל 🧩 עד שתנעצו אותם (שלב 5). ‏Firefox: השתמשו ב-about:debugging ← «Load Temporary Add-on», ואז נעצו מתפריט הגלישה של סרגל הכלים.

בקרוב · ההתקנה החלקה ביותר לשולחן העבודה

⌨️ Windows: התקנה עם winget

ל-Windows יש מנהל חבילות מובנה. ברגע שהרשימה שלנו תאושר, אפליקציית שולחן העבודה מותקנת בפקודה אחת — ללא בקשת הורדה, וללא אזהרה שצריך לעבור:

winget install SubramanyaMysore.PolyglotFormFill

‏winget מביא את המתקין ובודק אותו מול סיכום ביקורת מפורסם לפני הרצתו. עדיין לא פעיל — הרשימה ממתינה לבדיקה במאגר Windows Package Manager. עד אז, השתמשו בהורדה הישירה שלהלן.

🖥️ אפליקציית שולחן עבודה ל-Windows — הורדה ישירה v1.0.1

מה Windows יציג לכם, ולמה. עדיין לא רכשנו תעודת חתימת קוד — הן נמכרות לחברות רשומות ועולות כמה מאות דולרים בשנה, ואנחנו מעדיפים לדחות זאת מאשר לגבות מכם עבורן. לכן Windows עדיין לא מזהה את שם המפרסם, ומציג את התיבה הכחולה הזו בפעם הראשונה שאתם מריצים את המתקין:
‏Windows הגן על המחשב שלכם ‏Microsoft Defender SmartScreen מנע מאפליקציה לא מזוהה להתחיל לפעול.
ההודעה הזו אומרת «לא ראיתי את המפרסם הזה קודם» — לא שיש משהו לא בסדר בקובץ. כדי להמשיך:
  1. לחצו על More info (קישור קטן בתוך התיבה הכחולה).
  2. לחצו על Run anyway.
זה מופיע פעם אחת, בהתקנה הראשונה. מעדיפים להימנע מכך לגמרי? השתמשו ב-winget שלמעלה, או בתוסף הדפדפן, שאינו מושפע.
הורדת המתקין (.exe)

בהפעלה הראשונה תגדירו ביטוי סיסמה — האפליקציה נעולה עד שתזינו אותו.

בדקו שההורדה היא בדיוק מה שפרסמנו

כל גרסה מפרטת את ה-SHA-256 של כל קובץ. הריצו זאת ב-PowerShell על הקובץ שהורדתם והשוו — אם שתי המחרוזות תואמות, הקובץ הגיע שלם וללא שינוי.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

ערכי גיבוב מפורסמים עבור גרסה זו:

release-manifest.json

הנתונים שלכם נשארים על המכשיר שלכם; אנחנו לעולם לא רואים אותם. ראו את מדיניות הפרטיות.
