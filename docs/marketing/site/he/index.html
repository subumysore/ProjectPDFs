התכונה המובילה

הפכו PDF שאי-אפשר למלא לטופס שאפשר באמת למלא

‏PDF שטוח ללא שדות טופס — או אפילו צילום או סריקה שלו — הופך לטופס אמיתי הניתן למילוי תוך שניות. בלי «להדפיס, לכתוב ביד, לסרוק מחדש». ובלי להעלות אותו לאיזה אתר כדי לעשות זאת.

🧩
לא ניתן למילוי ← ניתן למילוי

כל PDF שטוח, סריקה או צילום הופך לטופס הניתן לעריכה

כוונו אותו אל PDF שאין בו תיבות למילוי, או אפילו אל תמונה של טופס נייר. ה-OCR שעל המכשיר קורא את הפריסה, מוצא לאן שייך כל שדה, ממקם שם שדות טופס אמיתיים, וממלא אותם מהכספת שלכם — הכול על המחשב שלכם, בלי שדבר יועלה. ואז ייצאו PDF נקי וממולא.

Downloads hosted on Oracle Cloud. The Windows installer is code-signed by a Microsoft-trusted authority (verified publisher: Subramanya Mysore) — no “unknown publisher” warning. The browser extension is in Chrome Web Store review; for now it installs via developer mode. macOS & Linux next.
