3.저희의 핵심 개인정보 원칙

본 서비스는 저희가 사용자의 사용자 콘텐츠를 보지 않고, 저장하지 않고, 전송하지 않으며, 사용자가 의도하지 않은 어디로도 보내지 않도록 설계되었습니다. 구체적으로:

  1. 기기 내 처리. 읽기/렌더링, OCR, 번역, 필드 감지, 작성, 내보내기, 서명은 사용자의 기기에서 로컬로 수행됩니다. 저희는 그것들을 위해 사용자의 사용자 콘텐츠를 받지 않습니다.
  2. 저희의 수집 없음. 저희는 사용자의 사용자 콘텐츠를 수집, 수신, 접근, 저장하지 않습니다. 계정이 필요 없으며, 사용자의 사용자 콘텐츠를 저희에게 업로드하는 일도 없습니다.
  3. 사용자 주도 전송만. 사용자 콘텐츠가 사용자의 기기를 떠나는 것은 사용자가 특정 행위를 개시할 때뿐이며, 오직 사용자가 선택한 목적지로만 갑니다:
    (a) 완성된 양식 제출 — 사용자의 기기에서 사용자가 선택한 수신자(예: 정부 또는 공급업체 사이트)에게 직접 전송됩니다. 저희는 그것을 프록시하거나, 가로채거나, 수신하거나, 보관하거나, 접근하지 않습니다.
    (b) 웹 검색(선택) — 사용자가 입력한 검색어만 결과를 반환하기 위해 제3자 검색 제공자(DuckDuckGo)에게 직접 전송됩니다. 어떤 사용자 콘텐츠, 보관함 데이터, 식별 정보도 전송되지 않습니다. URL을 입력하면 이를 완전히 피할 수 있습니다.
    이상이 콘텐츠 또는 검색어가 사용자의 기기를 떠나는 유일한 상황입니다 — 각각 사용자가 개시하고, 명확히 표시되며, 사용자가 선택한 목적지로 향합니다.

4.저희가 처리할 수 있는 제한적 비콘텐츠 데이터

  • 소프트웨어 배포 및 업데이트. 본 서비스를 다운로드/업데이트하거나 그 자산(업데이트, 글꼴, 모델)을 다운로드하면 해당 채널로 일방향 요청이 이루어지며, 그 채널은 독립적 관리자로서 자체 방침에 따라 기술 데이터(예: IP)를 처리할 수 있습니다. 이것은 사용자의 기기로의 다운로드이며, 사용자의 사용자 콘텐츠를 업로드할 어떤 경로도 제공하지 않습니다.

  • 자발적 소통. 지원팀에 연락하시면, 저희는 답변을 위해 제공하신 내용을 처리합니다.
