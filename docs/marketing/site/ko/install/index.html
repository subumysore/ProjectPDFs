설치

브라우저 확장 프로그램으로 시작하세요 — 가장 빠른 진입 방법이며 핵심 작업을 수행합니다. 데스크톱 앱은 서명, 기록, 오프라인 작업을 더합니다.

여기서 시작 · 가장 쉬움

🧩 브라우저 확장 프로그램 v1.0.3

확장 프로그램 다운로드 (.zip)

스토어에 등록되기 전까지는 개발자 모드로 로드하세요:

  1. 다운로드 파일을 폴더에 압축 해제합니다.
  2. chrome://extensions (또는 edge://extensions)를 엽니다.
  3. 개발자 모드를 켭니다(오른쪽 상단).
  4. "압축해제된 확장 프로그램을 로드합니다"를 클릭 → 압축 해제한 폴더를 선택합니다. 이제 PolyglotFormFill이 확장 프로그램 목록에 나타납니다.
  5. 찾기 쉽도록 도구 모음에 고정하세요: 브라우저 오른쪽 상단 근처의 퍼즐 조각 아이콘 🧩(확장 프로그램 메뉴)을 클릭하고, PolyglotFormFill을 찾아 그 옆의 핀 📌을 클릭합니다. 이제 아이콘이 도구 모음에 자리 잡습니다.
  6. 그 도구 모음의 PolyglotFormFill 아이콘을 클릭 → 암호구절을 설정합니다(또는 패스키로 잠금 해제).
  7. 팝업의 "내 정보"에서 각 필드(예: full_name, email, phone)와 그 값을 입력한 뒤 "필드 저장"을 클릭합니다. 이것들은 사용자의 기기에 암호화되어 저장됩니다. 그런 다음 양식을 열고 "이 페이지 작성"을 클릭합니다.

로드 직후 도구 모음 아이콘이 보이지 않나요? 정상입니다 — Chrome은 고정할 때까지(5단계) 새 확장 프로그램을 🧩 퍼즐 조각 메뉴 안에 숨깁니다. Firefox: about:debugging → "임시 부가 기능 로드"를 사용한 뒤 도구 모음 오버플로에서 고정하세요.

곧 제공 · 가장 매끄러운 데스크톱 설치

⌨️ Windows: winget으로 설치

Windows에는 기본 패키지 관리자가 있습니다. 저희 등록이 승인되면 데스크톱 앱은 명령 하나로 설치됩니다 — 다운로드 확인창도, 클릭해 넘길 경고도 없습니다:

winget install SubramanyaMysore.PolyglotFormFill

winget은 설치 관리자를 가져와 실행 전에 게시된 체크섬과 대조합니다. 아직 사용할 수 없습니다 — 등록이 Windows Package Manager 저장소에서 심사 대기 중입니다. 그때까지는 아래의 직접 다운로드를 이용하세요.

🖥️ Windows 데스크톱 앱 — 직접 다운로드 v1.0.5

Digitally signed. This installer is code-signed by a Microsoft-trusted certificate authority, so Windows recognises the publisher and installs it without a SmartScreen warning. You can still verify the exact file below with its published SHA-256.
설치 관리자 다운로드 (.exe)

첫 실행 시 암호구절을 설정합니다 — 입력하기 전까지 앱은 잠겨 있습니다.

다운로드가 저희가 게시한 것과 정확히 일치하는지 확인

모든 릴리스는 각 파일의 SHA-256을 표기합니다. 다운로드한 파일에 대해 PowerShell에서 다음을 실행하고 비교하세요 — 두 문자열이 일치하면 파일은 손상 없이 변조되지 않은 채 도착한 것입니다.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

게시된 해시 — 이번 릴리스:

release-manifest.json

사용자의 데이터는 사용자의 기기에 머물며, 저희는 결코 보지 않습니다. 참조하세요 개인정보처리방침.
