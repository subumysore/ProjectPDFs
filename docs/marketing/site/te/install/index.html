🧩 బ్రౌజర్ ఎక్స్‌టెన్షన్ v1.0.3

ఎక్స్‌టెన్షన్ డౌన్‌లోడ్ చేయండి (.zip)

ఇది స్టోర్‌లలోకి వచ్చే వరకు, డెవలపర్ మోడ్‌లో లోడ్ చేయండి:

  1. డౌన్‌లోడ్‌ను ఒక ఫోల్డర్‌కి అన్‌జిప్ చేయండి.
  2. chrome://extensions (లేదా edge://extensions) తెరవండి.
  3. Developer mode ఆన్ చేయండి (కుడి-ఎగువన).
  4. Load unpacked క్లిక్ చేయండి → అన్‌జిప్ చేసిన ఫోల్డర్‌ను ఎంచుకోండి. PolyglotFormFill ఇప్పుడు మీ ఎక్స్‌టెన్షన్‌ల జాబితాలో కనిపిస్తుంది.
  5. మీరు దాన్ని కనుగొనగలిగేలా టూల్‌బార్‌కి పిన్ చేయండి: బ్రౌజర్ కుడి-ఎగువన ఉన్న పజిల్-పీస్ ఐకాన్ 🧩 క్లిక్ చేయండి (అదే ఎక్స్‌టెన్షన్‌ల మెనూ), PolyglotFormFillని కనుగొని, దాని పక్కన ఉన్న పిన్ 📌 క్లిక్ చేయండి. దాని ఐకాన్ ఇప్పుడు మీ టూల్‌బార్‌లో ఉంటుంది.
  6. ఆ PolyglotFormFill టూల్‌బార్ ఐకాన్ క్లిక్ చేయండి → పాస్‌ఫ్రేజ్ సెట్ చేయండి (లేదా పాస్‌కీతో అన్‌లాక్ చేయండి).
  7. పాప్‌అప్‌లో “మీ వివరాలు” కింద, ప్రతి ఫీల్డ్‌ను (ఉదా. full_name, email, phone) మరియు దాని విలువను టైప్ చేసి, Save field నొక్కండి. ఇవి మీ పరికరంలో ఎన్‌క్రిప్ట్ చేయబడి నిల్వ చేయబడతాయి. తర్వాత ఒక ఫారమ్ తెరిచి Fill this page క్లిక్ చేయండి.

లోడ్ చేసిన వెంటనే టూల్‌బార్ ఐకాన్ కనిపించలేదా? అది సాధారణమే — మీరు వాటిని పిన్ చేసే వరకు (దశ 5) Chrome కొత్త ఎక్స్‌టెన్షన్‌లను 🧩 పజిల్-పీస్ మెనూ వెనుక దాచిపెడుతుంది. Firefox: about:debugging → “Load Temporary Add-on” ఉపయోగించి, తర్వాత టూల్‌బార్ ఓవర్‌ఫ్లో నుండి పిన్ చేయండి.

⌨️ Windows: winget తో ఇన్‌స్టాల్ చేయండి

Windowsలో అంతర్నిర్మిత ప్యాకేజ్ మేనేజర్ ఉంది. మా జాబితా ఆమోదించబడిన తర్వాత, డెస్క్‌టాప్ యాప్ ఒక కమాండ్‌తో ఇన్‌స్టాల్ అవుతుంది — డౌన్‌లోడ్ ప్రాంప్ట్ లేదు, క్లిక్ చేయాల్సిన హెచ్చరిక లేదు:

winget install SubramanyaMysore.PolyglotFormFill

winget ఇన్‌స్టాలర్‌ను తీసుకువచ్చి, దాన్ని అమలు చేయడానికి ముందు ప్రచురించిన చెక్‌సమ్‌తో సరిపోల్చుతుంది. ఇంకా లైవ్‌లో లేదు — జాబితా Windows Package Manager రిపోజిటరీలో సమీక్ష కోసం ఎదురుచూస్తోంది. అప్పటివరకు, కింద ఉన్న ప్రత్యక్ష డౌన్‌లోడ్‌ను ఉపయోగించండి.

🖥️ Windows డెస్క్‌టాప్ యాప్ — ప్రత్యక్ష డౌన్‌లోడ్ v1.0.1

Windows మీకు ఏమి చూపిస్తుంది, ఎందుకు. మేము ఇంకా కోడ్-సైనింగ్ సర్టిఫికేట్ కొనలేదు — అవి నమోదిత కంపెనీలకు అమ్మబడతాయి మరియు సంవత్సరానికి కొన్ని వందల డాలర్లు ఖర్చవుతాయి, దాన్ని మీ నుండి వసూలు చేయడం కంటే వాయిదా వేయడాన్ని మేము ఇష్టపడతాము. అందువల్ల Windows ప్రచురణకర్త పేరును ఇంకా గుర్తించదు, మరియు మీరు ఇన్‌స్టాలర్‌ను మొదటిసారి అమలు చేసినప్పుడు ఈ నీలి బాక్స్‌ను చూపిస్తుంది:
Windows మీ PCని రక్షించింది Microsoft Defender SmartScreen గుర్తించని యాప్ ప్రారంభం కాకుండా నిరోధించింది.
ఆ సందేశం అర్థం “ఈ ప్రచురణకర్తను నేను ఇంతకుముందు చూడలేదు” — ఫైల్‌లో ఏదో తప్పు ఉందని కాదు. కొనసాగించడానికి:
  1. More info క్లిక్ చేయండి (నీలి బాక్స్‌లోని చిన్న లింక్).
  2. Run anyway క్లిక్ చేయండి.
ఇది మొదటి ఇన్‌స్టాల్‌లో ఒకసారి మాత్రమే కనిపిస్తుంది. దాన్ని పూర్తిగా నివారించాలనుకుంటున్నారా? పైన ఉన్న winget, లేదా దీని ప్రభావం లేని బ్రౌజర్ ఎక్స్‌టెన్షన్‌ను ఉపయోగించండి.
ఇన్‌స్టాలర్ డౌన్‌లోడ్ చేయండి (.exe)

మొదటి ప్రారంభంలో మీరు పాస్‌ఫ్రేజ్ సెట్ చేస్తారు — మీరు దాన్ని నమోదు చేసే వరకు యాప్ లాక్ చేయబడి ఉంటుంది.

మేము ప్రచురించినది సరిగ్గా ఉందో లేదో డౌన్‌లోడ్‌ను తనిఖీ చేయండి

ప్రతి విడుదల ప్రతి ఫైల్ యొక్క SHA-256ని జాబితా చేస్తుంది. మీరు డౌన్‌లోడ్ చేసిన ఫైల్‌పై PowerShellలో దీన్ని అమలు చేసి సరిపోల్చండి — రెండు స్ట్రింగ్‌లు సరిపోతే, ఫైల్ చెక్కుచెదరకుండా, మార్చకుండా వచ్చింది.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

ప్రచురించిన హ్యాష్‌లు ఈ విడుదల:

release-manifest.json

మీ డేటా మీ పరికరంలోనే ఉంటుంది; మేము దాన్ని ఎప్పటికీ చూడము. చూడండి గోప్యతా విధానం.
