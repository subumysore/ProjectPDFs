🧩 ব্রাউজার এক্সটেনশন v1.0.3

এক্সটেনশন ডাউনলোড করুন (.zip)

স্টোরে আসার আগ পর্যন্ত, এটি ডেভেলপার মোডে লোড করুন:

  1. ডাউনলোডটি একটি ফোল্ডারে আনজিপ করুন।
  2. chrome://extensions (বা edge://extensions) খুলুন।
  3. Developer mode চালু করুন (উপরে-ডানে)।
  4. Load unpacked-এ ক্লিক করুন → আনজিপ করা ফোল্ডারটি নির্বাচন করুন। PolyglotFormFill এখন আপনার এক্সটেনশন তালিকায় দেখা যাবে।
  5. এটিকে টুলবারে পিন করুন যাতে আপনি খুঁজে পান: ব্রাউজারের উপরে-ডানে ধাঁধা-টুকরো আইকন 🧩-এ ক্লিক করুন (এটি Extensions মেনু), PolyglotFormFill খুঁজুন এবং তার পাশের পিন 📌-এ ক্লিক করুন। এর আইকন এখন আপনার টুলবারে থাকবে।
  6. সেই PolyglotFormFill টুলবার আইকনে ক্লিক করুন → একটি পাসফ্রেজ সেট করুন (বা পাসকি দিয়ে আনলক করুন)।
  7. পপআপে "Your details"-এর অধীনে, প্রতিটি ফিল্ড (যেমন full_name, email, phone) ও তার মান টাইপ করুন, তারপর Save field করুন। এগুলি আপনার ডিভাইসে এনক্রিপ্ট করে সংরক্ষিত হয়। তারপর একটি ফর্ম খুলুন এবং Fill this page-এ ক্লিক করুন।

লোড করার ঠিক পরেই টুলবার আইকন দেখছেন না? এটি স্বাভাবিক — Chrome নতুন এক্সটেনশনগুলি 🧩 ধাঁধা-টুকরো মেনুতে লুকিয়ে রাখে যতক্ষণ না আপনি সেগুলি পিন করেন (ধাপ ৫)। Firefox: about:debugging → "Load Temporary Add-on" ব্যবহার করুন, তারপর টুলবার ওভারফ্লো থেকে পিন করুন।

⌨️ Windows: winget দিয়ে ইনস্টল করুন

Windows-এ একটি অন্তর্নির্মিত প্যাকেজ ম্যানেজার আছে। আমাদের তালিকা অনুমোদিত হলে, ডেস্কটপ অ্যাপ একটি কমান্ডেই ইনস্টল হয় — কোনো ডাউনলোড প্রম্পট নয়, এবং ক্লিক করে পার হওয়ার কোনো সতর্কতা নয়:

winget install SubramanyaMysore.PolyglotFormFill

winget ইনস্টলারটি এনে চালানোর আগে একটি প্রকাশিত চেকসামের বিপরীতে পরীক্ষা করে। এখনও লাইভ নয় — তালিকাটি Windows Package Manager রিপোজিটরিতে পর্যালোচনার অপেক্ষায়। ততক্ষণ পর্যন্ত, নিচের সরাসরি ডাউনলোড ব্যবহার করুন।

🖥️ Windows ডেস্কটপ অ্যাপ — সরাসরি ডাউনলোড v1.0.6

Digitally signed. This installer is code-signed by a Microsoft-trusted certificate authority, so Windows recognises the publisher and installs it without a SmartScreen warning. You can still verify the exact file below with its published SHA-256.
ইনস্টলার ডাউনলোড করুন (.exe)

প্রথমবার চালু করার সময় আপনি একটি পাসফ্রেজ সেট করবেন — আপনি এটি প্রবেশ না করা পর্যন্ত অ্যাপটি লক থাকে।

ডাউনলোডটি ঠিক আমরা যা প্রকাশ করেছি তা কিনা যাচাই করুন

প্রতিটি রিলিজ প্রতিটি ফাইলের SHA-256 তালিকাভুক্ত করে। আপনার ডাউনলোড করা ফাইলে এটি PowerShell-এ চালান এবং তুলনা করুন — যদি দুটি স্ট্রিং মিলে যায়, তবে ফাইলটি অক্ষত ও অপরিবর্তিত অবস্থায় পৌঁছেছে।

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

release-manifest.json
