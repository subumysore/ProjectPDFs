यहाँ से शुरू करें · सबसे आसान

🧩 ब्राउज़र एक्सटेंशन v1.0.3

एक्सटेंशन डाउनलोड करें (.zip)

जब तक यह स्टोर पर न आ जाए, इसे डेवलपर मोड में लोड करें:

  1. डाउनलोड को एक फ़ोल्डर में अनज़िप करें।
  2. chrome://extensions (या edge://extensions) खोलें।
  3. Developer mode चालू करें (ऊपर-दाएँ)।
  4. Load unpacked पर क्लिक करें → अनज़िप किया गया फ़ोल्डर चुनें। PolyglotFormFill अब आपकी एक्सटेंशन सूची में दिखाई देता है।
  5. इसे टूलबार पर पिन करें ताकि आप इसे ढूँढ सकें: ब्राउज़र के ऊपर-दाएँ पास पहेली-टुकड़े के आइकन 🧩 पर क्लिक करें (यह Extensions मेनू है), PolyglotFormFill ढूँढें, और उसके बगल में पिन 📌 पर क्लिक करें। इसका आइकन अब आपके टूलबार पर रहता है।
  6. उस PolyglotFormFill टूलबार आइकन पर क्लिक करें → एक पासफ़्रेज़ सेट करें (या पासकी से अनलॉक करें)।
  7. पॉपअप में "Your details" के अंतर्गत, प्रत्येक फ़ील्ड (जैसे full_name, email, phone) और उसका मान टाइप करें, फिर Save field करें। ये आपके डिवाइस पर एन्क्रिप्टेड रूप में संग्रहीत होते हैं। फिर एक फ़ॉर्म खोलें और Fill this page पर क्लिक करें।

लोड करने के तुरंत बाद टूलबार आइकन नहीं दिखा? यह सामान्य है — Chrome नई एक्सटेंशन को 🧩 पहेली-टुकड़े के मेनू में तब तक छिपाता है जब तक आप उन्हें पिन न करें (चरण 5)। Firefox: about:debugging → "Load Temporary Add-on" का उपयोग करें, फिर टूलबार ओवरफ़्लो से पिन करें।

⌨️ Windows: winget से इंस्टॉल करें

Windows में एक अंतर्निहित पैकेज मैनेजर है। एक बार हमारी लिस्टिंग स्वीकृत हो जाने पर, डेस्कटॉप ऐप एक ही कमांड से इंस्टॉल होता है — कोई डाउनलोड संकेत नहीं, और कोई चेतावनी नहीं जिसे क्लिक करके पार करना पड़े:

winget install SubramanyaMysore.PolyglotFormFill

winget इंस्टॉलर लाता है और चलाने से पहले उसे एक प्रकाशित चेकसम के विरुद्ध जाँचता है। अभी लाइव नहीं है — लिस्टिंग Windows Package Manager रिपॉज़िटरी में समीक्षा की प्रतीक्षा में है। तब तक, नीचे दिए गए सीधे डाउनलोड का उपयोग करें।

🖥️ Windows डेस्कटॉप ऐप — सीधा डाउनलोड v1.0.5

Digitally signed. This installer is code-signed by a Microsoft-trusted certificate authority, so Windows recognises the publisher and installs it without a SmartScreen warning. You can still verify the exact file below with its published SHA-256.
इंस्टॉलर डाउनलोड करें (.exe)

पहली बार शुरू करने पर आप एक पासफ़्रेज़ सेट करेंगे — जब तक आप इसे दर्ज नहीं करते, ऐप बंद रहता है।

जाँचें कि डाउनलोड ठीक वही है जो हमने प्रकाशित किया

हर रिलीज़ प्रत्येक फ़ाइल का SHA-256 सूचीबद्ध करती है। आपके द्वारा डाउनलोड की गई फ़ाइल पर इसे PowerShell में चलाएँ और तुलना करें — यदि दोनों स्ट्रिंग मेल खाती हैं, तो फ़ाइल बरकरार और अपरिवर्तित पहुँची है।

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

इसके लिए प्रकाशित हैश यह रिलीज़:

release-manifest.json

आपका डेटा आपके डिवाइस पर रहता है; हम इसे कभी नहीं देखते। देखें गोपनीयता नीति.
