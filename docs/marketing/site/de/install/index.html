Installieren

Beginnen Sie mit der Browser-Erweiterung — sie ist der schnellste Weg und erledigt die Kernaufgabe. Die Desktop-App ergänzt Signieren, Verlauf und Offline-Arbeit.

Hier beginnen · am einfachsten

🧩 Browser-Erweiterung v1.0.1

Erweiterung herunterladen (.zip)

Bis sie in den Stores ist, laden Sie sie im Entwicklermodus:

  1. Entpacken Sie den Download in einen Ordner.
  2. Öffnen Sie chrome://extensions (oder edge://extensions).
  3. Aktivieren Sie den Entwicklermodus (oben rechts).
  4. Klicken Sie auf Entpackte Erweiterung laden → wählen Sie den entpackten Ordner aus. PolyglotFormFill erscheint nun in Ihrer Erweiterungsliste.
  5. Heften Sie sie an die Symbolleiste, damit Sie sie finden: Klicken Sie auf das Puzzleteil-Symbol 🧩 oben rechts im Browser (das ist das Erweiterungsmenü), suchen Sie PolyglotFormFill und klicken Sie auf die Stecknadel 📌 daneben. Ihr Symbol sitzt nun in Ihrer Symbolleiste.
  6. Klicken Sie auf dieses PolyglotFormFill-Symbol in der Symbolleiste → legen Sie eine Passphrase fest (oder entsperren Sie mit einem Passkey).
  7. Geben Sie unter „Ihre Angaben“ im Popup jedes Feld (z. B. full_name, email, phone) und seinen Wert ein, dann Feld speichern. Diese werden verschlüsselt auf Ihrem Gerät gespeichert. Öffnen Sie dann ein Formular und klicken Sie auf Diese Seite ausfüllen.

Sehen Sie direkt nach dem Laden kein Symbol in der Symbolleiste? Das ist normal — Chrome verbirgt neue Erweiterungen hinter dem Puzzleteil-Menü 🧩, bis Sie sie anheften (Schritt 5). Firefox: Verwenden Sie about:debugging → „Temporäres Add-on laden“ und heften Sie es dann aus dem Symbolleisten-Überlauf an.

In Kürze · die reibungsloseste Desktop-Installation

⌨️ Windows: mit winget installieren

Windows verfügt über einen integrierten Paketmanager. Sobald unser Eintrag genehmigt ist, installiert sich die Desktop-App mit einem einzigen Befehl — keine Download-Aufforderung und keine Warnung, die Sie wegklicken müssen:

winget install SubramanyaMysore.PolyglotFormFill

winget lädt das Installationsprogramm herunter und prüft es vor der Ausführung gegen eine veröffentlichte Prüfsumme. Noch nicht live — der Eintrag wartet auf die Prüfung im Windows-Package-Manager-Repository. Verwenden Sie bis dahin den direkten Download unten.

🖥️ Windows-Desktop-App — direkter Download v1.0.0

Was Windows Ihnen zeigen wird und warum. Wir haben noch kein Code-Signing-Zertifikat gekauft — sie werden an registrierte Unternehmen verkauft und kosten einige Hundert Dollar pro Jahr, und wir schieben das lieber auf, als es Ihnen in Rechnung zu stellen. Windows erkennt daher den Herausgebernamen noch nicht und zeigt beim ersten Ausführen des Installationsprogramms dieses blaue Feld:
Der Computer wurde durch Windows geschützt Microsoft Defender SmartScreen hat den Start einer nicht erkannten App verhindert.
Diese Meldung bedeutet „Ich habe diesen Herausgeber noch nie gesehen“ — nicht, dass mit der Datei etwas nicht stimmt. So fahren Sie fort:
  1. Klicken Sie auf Weitere Informationen (kleiner Link im blauen Feld).
  2. Klicken Sie auf Trotzdem ausführen.
Es erscheint einmal, bei der ersten Installation. Möchten Sie es ganz vermeiden? Verwenden Sie winget oben oder die Browser-Erweiterung, die nicht betroffen ist.

Prüfen Sie, ob der Download genau dem entspricht, was wir veröffentlicht haben

Jede Version listet den SHA-256 jeder Datei auf. Führen Sie dies in PowerShell für die heruntergeladene Datei aus und vergleichen Sie — stimmen die beiden Zeichenfolgen überein, ist die Datei intakt und unverändert angekommen.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256
