ಬ್ರೌಸರ್ ವಿಸ್ತರಣೆಯೊಂದಿಗೆ ಪ್ರಾರಂಭಿಸಿ — ಇದು ಅತ್ಯಂತ ವೇಗದ ಮಾರ್ಗ ಮತ್ತು ಪ್ರಮುಖ ಕೆಲಸವನ್ನು ಮಾಡುತ್ತದೆ. ಡೆಸ್ಕ್‌ಟಾಪ್ ಅಪ್ಲಿಕೇಶನ್ ಸಹಿ, ಇತಿಹಾಸ ಮತ್ತು ಆಫ್‌ಲೈನ್ ಕೆಲಸವನ್ನು ಸೇರಿಸುತ್ತದೆ.

ಇಲ್ಲಿ ಪ್ರಾರಂಭಿಸಿ · ಅತ್ಯಂತ ಸುಲಭ

🧩 ಬ್ರೌಸರ್ ವಿಸ್ತರಣೆ v1.0.3

ವಿಸ್ತರಣೆಯನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ (.zip)

ಇದು ಸ್ಟೋರ್‌ಗಳಿಗೆ ಬರುವವರೆಗೆ, ಡೆವಲಪರ್ ಮೋಡ್‌ನಲ್ಲಿ ಲೋಡ್ ಮಾಡಿ:

  1. ಡೌನ್‌ಲೋಡ್ ಅನ್ನು ಒಂದು ಫೋಲ್ಡರ್‌ಗೆ ಅನ್‌ಜಿಪ್ ಮಾಡಿ.
  2. chrome://extensions (ಅಥವಾ edge://extensions) ತೆರೆಯಿರಿ.
  3. Developer mode ಅನ್ನು ಆನ್ ಮಾಡಿ (ಬಲ-ಮೇಲ್ಭಾಗ).
  4. Load unpacked ಕ್ಲಿಕ್ ಮಾಡಿ → ಅನ್‌ಜಿಪ್ ಮಾಡಿದ ಫೋಲ್ಡರ್ ಅನ್ನು ಆಯ್ಕೆಮಾಡಿ. PolyglotFormFill ಈಗ ನಿಮ್ಮ ವಿಸ್ತರಣೆಗಳ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ.
  5. ನೀವು ಅದನ್ನು ಕಂಡುಹಿಡಿಯಲು ಟೂಲ್‌ಬಾರ್‌ಗೆ ಪಿನ್ ಮಾಡಿ: ಬ್ರೌಸರ್‌ನ ಬಲ-ಮೇಲ್ಭಾಗದಲ್ಲಿರುವ ಒಗಟು-ತುಣುಕು ಐಕಾನ್ 🧩 ಅನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ (ಅದೇ ವಿಸ್ತರಣೆಗಳ ಮೆನು), PolyglotFormFill ಅನ್ನು ಕಂಡುಹಿಡಿದು, ಅದರ ಪಕ್ಕದಲ್ಲಿರುವ ಪಿನ್ 📌 ಅನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ. ಅದರ ಐಕಾನ್ ಈಗ ನಿಮ್ಮ ಟೂಲ್‌ಬಾರ್‌ನಲ್ಲಿ ಇರುತ್ತದೆ.
  6. ಆ PolyglotFormFill ಟೂಲ್‌ಬಾರ್ ಐಕಾನ್ ಅನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ → ಪಾಸ್‌ಫ್ರೇಸ್ ಹೊಂದಿಸಿ (ಅಥವಾ ಪಾಸ್‌ಕೀ ಮೂಲಕ ಅನ್‌ಲಾಕ್ ಮಾಡಿ).
  7. ಪಾಪ್‌ಅಪ್‌ನಲ್ಲಿ “ನಿಮ್ಮ ವಿವರಗಳು” ಅಡಿಯಲ್ಲಿ, ಪ್ರತಿ ಕ್ಷೇತ್ರವನ್ನು (ಉದಾ. full_name, email, phone) ಮತ್ತು ಅದರ ಮೌಲ್ಯವನ್ನು ಟೈಪ್ ಮಾಡಿ, ನಂತರ Save field ಒತ್ತಿರಿ. ಇವು ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ ಎನ್‌ಕ್ರಿಪ್ಟ್ ಮಾಡಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತವೆ. ನಂತರ ಒಂದು ನಮೂನೆಯನ್ನು ತೆರೆದು Fill this page ಕ್ಲಿಕ್ ಮಾಡಿ.

ಲೋಡ್ ಮಾಡಿದ ತಕ್ಷಣ ಟೂಲ್‌ಬಾರ್ ಐಕಾನ್ ಕಾಣಿಸುತ್ತಿಲ್ಲವೇ? ಅದು ಸಾಮಾನ್ಯ — ನೀವು ಅವುಗಳನ್ನು ಪಿನ್ ಮಾಡುವವರೆಗೆ (ಹಂತ 5) Chrome ಹೊಸ ವಿಸ್ತರಣೆಗಳನ್ನು 🧩 ಒಗಟು-ತುಣುಕು ಮೆನುವಿನ ಹಿಂದೆ ಮರೆಮಾಡುತ್ತದೆ. Firefox: about:debugging → “Load Temporary Add-on” ಬಳಸಿ, ನಂತರ ಟೂಲ್‌ಬಾರ್ ಓವರ್‌ಫ್ಲೋನಿಂದ ಪಿನ್ ಮಾಡಿ.

ಶೀಘ್ರದಲ್ಲೇ ಬರಲಿದೆ · ಅತ್ಯಂತ ಸುಗಮ ಡೆಸ್ಕ್‌ಟಾಪ್ ಸ್ಥಾಪನೆ

⌨️ Windows: winget ಮೂಲಕ ಸ್ಥಾಪಿಸಿ

Windows ನಲ್ಲಿ ಅಂತರ್ನಿರ್ಮಿತ ಪ್ಯಾಕೇಜ್ ಮ್ಯಾನೇಜರ್ ಇದೆ. ನಮ್ಮ ಪಟ್ಟಿ ಅನುಮೋದಿಸಿದ ನಂತರ, ಡೆಸ್ಕ್‌ಟಾಪ್ ಅಪ್ಲಿಕೇಶನ್ ಒಂದೇ ಆದೇಶದೊಂದಿಗೆ ಸ್ಥಾಪಿಸುತ್ತದೆ — ಡೌನ್‌ಲೋಡ್ ಪ್ರಾಂಪ್ಟ್ ಇಲ್ಲ, ಕ್ಲಿಕ್ ಮಾಡಬೇಕಾದ ಎಚ್ಚರಿಕೆ ಇಲ್ಲ:

winget install SubramanyaMysore.PolyglotFormFill

winget ಸ್ಥಾಪಕವನ್ನು ತರುತ್ತದೆ ಮತ್ತು ಅದನ್ನು ಚಲಾಯಿಸುವ ಮೊದಲು ಪ್ರಕಟಿಸಿದ ಚೆಕ್‌ಸಮ್‌ನೊಂದಿಗೆ ಪರಿಶೀಲಿಸುತ್ತದೆ. ಇನ್ನೂ ಲೈವ್ ಆಗಿಲ್ಲ — ಪಟ್ಟಿ Windows Package Manager ಭಂಡಾರದಲ್ಲಿ ಪರಿಶೀಲನೆಗಾಗಿ ಕಾಯುತ್ತಿದೆ. ಅಲ್ಲಿಯವರೆಗೆ, ಕೆಳಗಿನ ನೇರ ಡೌನ್‌ಲೋಡ್ ಅನ್ನು ಬಳಸಿ.

🖥️ Windows ಡೆಸ್ಕ್‌ಟಾಪ್ ಅಪ್ಲಿಕೇಶನ್ — ನೇರ ಡೌನ್‌ಲೋಡ್ v1.0.2

Windows ನಿಮಗೆ ಏನನ್ನು ತೋರಿಸುತ್ತದೆ, ಮತ್ತು ಏಕೆ. ನಾವು ಇನ್ನೂ ಕೋಡ್-ಸೈನಿಂಗ್ ಪ್ರಮಾಣಪತ್ರವನ್ನು ಖರೀದಿಸಿಲ್ಲ — ಅವು ನೋಂದಾಯಿತ ಕಂಪನಿಗಳಿಗೆ ಮಾರಲಾಗುತ್ತವೆ ಮತ್ತು ವರ್ಷಕ್ಕೆ ಕೆಲವು ನೂರು ಡಾಲರ್‌ಗಳ ವೆಚ್ಚವಾಗುತ್ತದೆ, ಅದನ್ನು ನಿಮ್ಮಿಂದ ವಸೂಲಿ ಮಾಡುವುದಕ್ಕಿಂತ ಮುಂದೂಡಲು ನಾವು ಬಯಸುತ್ತೇವೆ. ಆದ್ದರಿಂದ Windows ಪ್ರಕಾಶಕರ ಹೆಸರನ್ನು ಇನ್ನೂ ಗುರುತಿಸುವುದಿಲ್ಲ, ಮತ್ತು ನೀವು ಸ್ಥಾಪಕವನ್ನು ಮೊದಲ ಬಾರಿ ಚಲಾಯಿಸಿದಾಗ ಈ ನೀಲಿ ಪೆಟ್ಟಿಗೆಯನ್ನು ತೋರಿಸುತ್ತದೆ:
Windows ನಿಮ್ಮ PC ಅನ್ನು ರಕ್ಷಿಸಿತು Microsoft Defender SmartScreen ಗುರುತಿಸದ ಅಪ್ಲಿಕೇಶನ್ ಪ್ರಾರಂಭವಾಗುವುದನ್ನು ತಡೆಯಿತು.
ಆ ಸಂದೇಶದ ಅರ್ಥ “ಈ ಪ್ರಕಾಶಕರನ್ನು ನಾನು ಈ ಮೊದಲು ನೋಡಿಲ್ಲ” — ಫೈಲ್‌ನಲ್ಲಿ ಏನಾದರೂ ತಪ್ಪಿದೆ ಎಂದಲ್ಲ. ಮುಂದುವರಿಸಲು:
  1. More info ಕ್ಲಿಕ್ ಮಾಡಿ (ನೀಲಿ ಪೆಟ್ಟಿಗೆಯೊಳಗಿನ ಸಣ್ಣ ಲಿಂಕ್).
  2. Run anyway ಕ್ಲಿಕ್ ಮಾಡಿ.
ಇದು ಮೊದಲ ಸ್ಥಾಪನೆಯಲ್ಲಿ ಒಮ್ಮೆ ಮಾತ್ರ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ. ಅದನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ತಪ್ಪಿಸಲು ಬಯಸುವಿರಾ? ಮೇಲಿನ winget, ಅಥವಾ ಇದರಿಂದ ಪ್ರಭಾವಿತವಾಗದ ಬ್ರೌಸರ್ ವಿಸ್ತರಣೆಯನ್ನು ಬಳಸಿ.
ಸ್ಥಾಪಕವನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ (.exe)

ಮೊದಲ ಪ್ರಾರಂಭದಲ್ಲಿ ನೀವು ಪಾಸ್‌ಫ್ರೇಸ್ ಹೊಂದಿಸುತ್ತೀರಿ — ನೀವು ಅದನ್ನು ನಮೂದಿಸುವವರೆಗೆ ಅಪ್ಲಿಕೇಶನ್ ಲಾಕ್ ಆಗಿರುತ್ತದೆ.

ನಾವು ಪ್ರಕಟಿಸಿದ್ದು ನಿಖರವಾಗಿ ಇದೆಯೇ ಎಂದು ಡೌನ್‌ಲೋಡ್ ಅನ್ನು ಪರಿಶೀಲಿಸಿ

ಪ್ರತಿ ಬಿಡುಗಡೆ ಪ್ರತಿ ಫೈಲ್‌ನ SHA-256 ಅನ್ನು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ. ನೀವು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿದ ಫೈಲ್‌ನಲ್ಲಿ PowerShell ನಲ್ಲಿ ಇದನ್ನು ಚಲಾಯಿಸಿ ಹೋಲಿಸಿ — ಎರಡು ಸ್ಟ್ರಿಂಗ್‌ಗಳು ಹೊಂದಿಕೆಯಾದರೆ, ಫೈಲ್ ಹಾಗೆಯೇ, ಬದಲಾಗದೆ ಬಂದಿದೆ.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

ಪ್ರಕಟಿಸಿದ ಹ್ಯಾಶ್‌ಗಳು ಈ ಬಿಡುಗಡೆ:

release-manifest.json

ನಿಮ್ಮ ಡೇಟಾ ನಿಮ್ಮ ಸಾಧನದಲ್ಲೇ ಉಳಿಯುತ್ತದೆ; ನಾವು ಅದನ್ನು ಎಂದಿಗೂ ನೋಡುವುದಿಲ್ಲ. ನೋಡಿ ಗೌಪ್ಯತಾ ನೀತಿ.
