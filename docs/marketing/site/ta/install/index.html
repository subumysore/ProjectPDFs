🧩 உலாவி நீட்டிப்பு v1.0.3

நீட்டிப்பைப் பதிவிறக்கவும் (.zip)

ஸ்டோர்களில் வரும் வரை, டெவலப்பர் பயன்முறையில் ஏற்றவும்:

  1. பதிவிறக்கத்தை ஒரு கோப்புறையில் அன்ஸிப் செய்யவும்.
  2. chrome://extensions (அல்லது edge://extensions) திறக்கவும்.
  3. Developer mode-ஐ இயக்கவும் (மேல்-வலது).
  4. Load unpacked-ஐ கிளிக் செய்யவும் → அன்ஸிப் செய்யப்பட்ட கோப்புறையைத் தேர்ந்தெடுக்கவும். PolyglotFormFill இப்போது உங்கள் நீட்டிப்புகள் பட்டியலில் தோன்றும்.
  5. உங்களால் கண்டுபிடிக்க முடியும்படி அதைக் கருவிப்பட்டியில் பொருத்தவும்: உலாவியின் மேல்-வலதுபுறத்தில் உள்ள புதிர்-துண்டு ஐகான் 🧩-ஐ கிளிக் செய்யவும் (அதுதான் நீட்டிப்புகள் மெனு), PolyglotFormFill-ஐக் கண்டறிந்து, அதற்கு அடுத்துள்ள பின் 📌-ஐ கிளிக் செய்யவும். அதன் ஐகான் இப்போது உங்கள் கருவிப்பட்டியில் இருக்கும்.
  6. அந்த PolyglotFormFill கருவிப்பட்டி ஐகானைக் கிளிக் செய்யவும் → ஒரு கடவுச்சொல்லை அமைக்கவும் (அல்லது ஒரு பாஸ்கீ மூலம் திறக்கவும்).
  7. பாப்-அப்பில் “உங்கள் விவரங்கள்” கீழ், ஒவ்வொரு புலத்தையும் (எ.கா. full_name, email, phone) அதன் மதிப்பையும் தட்டச்சு செய்து, Save field-ஐ அழுத்தவும். இவை உங்கள் சாதனத்தில் மறையாக்கம் செய்யப்பட்டு சேமிக்கப்படுகின்றன. பின்னர் ஒரு படிவத்தைத் திறந்து Fill this page-ஐ கிளிக் செய்யவும்.

ஏற்றிய உடனேயே கருவிப்பட்டி ஐகான் தெரியவில்லையா? அது இயல்பானது — நீங்கள் அவற்றைப் பொருத்தும் வரை (படி 5) Chrome புதிய நீட்டிப்புகளை 🧩 புதிர்-துண்டு மெனுவின் பின்னால் மறைக்கிறது. Firefox: about:debugging → “Load Temporary Add-on” பயன்படுத்தி, பின்னர் கருவிப்பட்டி மேல்வழிவிலிருந்து பொருத்தவும்.

⌨️ Windows: winget மூலம் நிறுவுங்கள்

Windows-இல் உள்ளமைந்த தொகுப்பு மேலாளர் உள்ளது. எங்கள் பட்டியல் அங்கீகரிக்கப்பட்டவுடன், டெஸ்க்டாப் பயன்பாடு ஒரே கட்டளையுடன் நிறுவப்படுகிறது — பதிவிறக்க அறிவிப்பு இல்லை, கிளிக் செய்ய எச்சரிக்கை இல்லை:

winget install SubramanyaMysore.PolyglotFormFill

winget நிறுவியை எடுத்து, இயக்குவதற்கு முன் வெளியிடப்பட்ட செக்சம்முடன் அதைச் சரிபார்க்கிறது. இன்னும் நேரலையில் இல்லை — பட்டியல் Windows Package Manager களஞ்சியத்தில் மதிப்பாய்வுக்காகக் காத்திருக்கிறது. அதுவரை, கீழே உள்ள நேரடிப் பதிவிறக்கத்தைப் பயன்படுத்தவும்.

🖥️ Windows டெஸ்க்டாப் பயன்பாடு — நேரடிப் பதிவிறக்கம் v1.0.2

Windows உங்களுக்கு என்ன காட்டும், ஏன். நாங்கள் இன்னும் ஒரு குறியீடு-கையொப்பச் சான்றிதழை வாங்கவில்லை — அவை பதிவுசெய்யப்பட்ட நிறுவனங்களுக்கு விற்கப்படுகின்றன, ஆண்டுக்கு சில நூறு டாலர்கள் செலவாகும், அதை உங்களிடமிருந்து வசூலிப்பதை விட தள்ளிப்போட விரும்புகிறோம். எனவே Windows வெளியீட்டாளரின் பெயரை இன்னும் அடையாளம் காணவில்லை, மேலும் நீங்கள் நிறுவியை முதல் முறை இயக்கும்போது இந்த நீலப் பெட்டியைக் காட்டுகிறது:
Windows உங்கள் PC-ஐப் பாதுகாத்தது Microsoft Defender SmartScreen அறியப்படாத ஒரு பயன்பாடு தொடங்குவதைத் தடுத்தது.
அந்தச் செய்தியின் அர்த்தம் “இந்த வெளியீட்டாளரை நான் இதற்கு முன் பார்த்ததில்லை” — கோப்பில் ஏதோ தவறு இருக்கிறது என்று அல்ல. தொடர:
  1. More info-ஐ கிளிக் செய்யவும் (நீலப் பெட்டிக்குள் உள்ள சிறிய இணைப்பு).
  2. Run anyway-ஐ கிளிக் செய்யவும்.
இது முதல் நிறுவலின் போது ஒருமுறை மட்டுமே தோன்றும். அதை முழுவதுமாகத் தவிர்க்க விரும்புகிறீர்களா? மேலே உள்ள winget-ஐ அல்லது இதனால் பாதிக்கப்படாத உலாவி நீட்டிப்பைப் பயன்படுத்தவும்.
நிறுவியைப் பதிவிறக்கவும் (.exe)

முதல் தொடக்கத்தில் நீங்கள் ஒரு கடவுச்சொல்லை அமைப்பீர்கள் — நீங்கள் அதை உள்ளிடும் வரை பயன்பாடு பூட்டப்பட்டிருக்கும்.

நாங்கள் வெளியிட்டது சரியாக இருக்கிறதா என்பதை பதிவிறக்கத்தில் சரிபார்க்கவும்

ஒவ்வொரு வெளியீடும் ஒவ்வொரு கோப்பின் SHA-256-ஐப் பட்டியலிடுகிறது. நீங்கள் பதிவிறக்கிய கோப்பில் PowerShell-இல் இதை இயக்கி ஒப்பிடுங்கள் — இரண்டு சரங்களும் பொருந்தினால், கோப்பு அப்படியே, மாற்றப்படாமல் வந்துள்ளது.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

வெளியிடப்பட்ட ஹாஷ்கள் இந்த வெளியீடு:

release-manifest.json

உங்கள் தரவு உங்கள் சாதனத்திலேயே இருக்கிறது; அதை நாங்கள் ஒருபோதும் பார்ப்பதில்லை. காண்க தனியுரிமைக் கொள்கை.
