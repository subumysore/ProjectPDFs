安装

从浏览器扩展开始——它是最快捷的入门方式，并能完成核心工作。桌面应用则增加了签名、历史记录和离线作业。

从这里开始 · 最简单

🧩 浏览器扩展 v1.0.3

下载扩展（.zip）

在上架应用商店之前，请以开发者模式加载：

  1. 将下载文件解压到一个文件夹。
  2. 打开 chrome://extensions（或 edge://extensions）。
  3. 开启开发者模式（右上角）。
  4. 点击“加载已解压的扩展程序”→ 选择解压后的文件夹。PolyglotFormFill 现在会出现在您的扩展列表中。
  5. 把它固定到工具栏以便找到：点击浏览器右上角附近的拼图图标 🧩（那是扩展菜单），找到 PolyglotFormFill，点击旁边的图钉 📌。它的图标现在就出现在您的工具栏上了。
  6. 点击工具栏上的 PolyglotFormFill 图标 → 设置一个口令（或用通行密钥解锁）。
  7. 在弹窗的“您的信息”下，逐一输入每个字段（例如 full_name、email、phone）及其值，然后点击“保存字段”。这些内容会在您的设备上加密存储。随后打开一份表单，点击“填写本页”。

加载后没立即看到工具栏图标？这很正常——Chrome 会把新扩展藏在 🧩 拼图菜单里，直到您固定它（第 5 步）。Firefox：使用 about:debugging →“加载临时附加组件”，然后从工具栏溢出菜单固定。

⌨️ Windows：用 winget 安装

Windows 内置了包管理器。一旦我们的条目获批，桌面应用只需一条命令即可安装——没有下载提示，也无需点掉任何警告：

winget install SubramanyaMysore.PolyglotFormFill

winget 会获取安装程序，并在运行前对照已发布的校验和进行核对。目前尚未上线——该条目正在 Windows Package Manager 仓库中等待审核。在此之前，请使用下方的直接下载。

核对下载文件与我们发布的完全一致

每个版本都会列出每个文件的 SHA-256。在 PowerShell 中对您下载的文件运行以下命令并比对——如果两个字符串一致，说明文件完整无损、未经篡改地送达。

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256
