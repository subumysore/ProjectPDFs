เริ่มจากส่วนขยายเบราว์เซอร์ — เป็นวิธีที่เร็วที่สุดและทำงานหลักได้ ส่วนแอปเดสก์ท็อปเพิ่มการลงลายเซ็น ประวัติ และการทำงานแบบออฟไลน์

เริ่มที่นี่ · ง่ายที่สุด

🧩 ส่วนขยายเบราว์เซอร์ v1.0.3

ดาวน์โหลดส่วนขยาย (.zip)

จนกว่าจะขึ้นสโตร์ ให้โหลดในโหมดนักพัฒนา:

  1. แตกไฟล์ที่ดาวน์โหลดลงในโฟลเดอร์
  2. เปิด chrome://extensions (หรือ edge://extensions)
  3. เปิดโหมดนักพัฒนา (มุมขวาบน)
  4. คลิก Load unpacked → เลือกโฟลเดอร์ที่แตกไฟล์ไว้ ตอนนี้ PolyglotFormFill จะปรากฏในรายการส่วนขยายของคุณ
  5. ปักหมุดไว้ที่แถบเครื่องมือเพื่อให้หาเจอ: คลิกไอคอนรูปจิ๊กซอว์ 🧩 ใกล้มุมขวาบนของเบราว์เซอร์ (นั่นคือเมนูส่วนขยาย) หา PolyglotFormFill แล้วคลิกหมุด 📌 ข้าง ๆ ไอคอนของมันจะอยู่บนแถบเครื่องมือของคุณแล้ว
  6. คลิกไอคอน PolyglotFormFill บนแถบเครื่องมือ → ตั้งวลีรหัสผ่าน (หรือปลดล็อกด้วยพาสคีย์)
  7. ใต้ “ข้อมูลของคุณ” ในป๊อปอัป พิมพ์แต่ละช่อง (เช่น full_name, email, phone) และค่าของมัน แล้วกด Save field ข้อมูลเหล่านี้ถูกจัดเก็บแบบเข้ารหัสบนอุปกรณ์ของคุณ จากนั้นเปิดแบบฟอร์มแล้วคลิก Fill this page

ไม่เห็นไอคอนบนแถบเครื่องมือทันทีหลังโหลดใช่ไหม? เป็นเรื่องปกติ — Chrome ซ่อนส่วนขยายใหม่ไว้หลังเมนูจิ๊กซอว์ 🧩 จนกว่าคุณจะปักหมุด (ขั้นตอนที่ 5) สำหรับ Firefox: ใช้ about:debugging → “Load Temporary Add-on” แล้วปักหมุดจากเมนูล้นของแถบเครื่องมือ

⌨️ Windows: ติดตั้งด้วย winget

Windows มีตัวจัดการแพ็กเกจในตัว เมื่อรายการของเราได้รับอนุมัติ แอปเดสก์ท็อปจะติดตั้งได้ด้วยคำสั่งเดียว — ไม่มีการแจ้งเตือนดาวน์โหลด และไม่มีคำเตือนให้คลิกผ่าน:

winget install SubramanyaMysore.PolyglotFormFill

winget ดึงตัวติดตั้งมาและตรวจสอบกับเช็คซัมที่เผยแพร่ไว้ก่อนเรียกใช้ ยังไม่พร้อมใช้งาน — รายการอยู่ระหว่างรอการตรวจสอบในคลัง Windows Package Manager จนกว่าจะถึงตอนนั้น โปรดใช้การดาวน์โหลดโดยตรงด้านล่าง

🖥️ แอปเดสก์ท็อป Windows — ดาวน์โหลดโดยตรง v1.0.2

สิ่งที่ Windows จะแสดงให้คุณเห็น และเหตุผล เรายังไม่ได้ซื้อใบรับรองการลงลายเซ็นโค้ด — มันขายให้บริษัทที่จดทะเบียนและมีค่าใช้จ่ายปีละไม่กี่ร้อยดอลลาร์ และเราขอเลื่อนออกไปมากกว่าจะเก็บเงินคุณสำหรับมัน Windows จึงยังไม่รู้จักชื่อผู้เผยแพร่ และจะแสดงกล่องสีน้ำเงินนี้ครั้งแรกที่คุณเรียกใช้ตัวติดตั้ง:
Windows ปกป้องพีซีของคุณ Microsoft Defender SmartScreen ป้องกันไม่ให้แอปที่ไม่รู้จักเริ่มทำงาน
ข้อความนั้นหมายความว่า “ฉันไม่เคยเห็นผู้เผยแพร่รายนี้มาก่อน” — ไม่ได้หมายความว่าไฟล์มีอะไรผิดปกติ หากต้องการดำเนินการต่อ:
  1. คลิก More info (ลิงก์เล็ก ๆ ในกล่องสีน้ำเงิน)
  2. คลิก Run anyway
มันปรากฏครั้งเดียว ตอนติดตั้งครั้งแรก อยากเลี่ยงทั้งหมดใช่ไหม? ใช้ winget ด้านบน หรือส่วนขยายเบราว์เซอร์ซึ่งไม่ได้รับผลกระทบ
ดาวน์โหลดตัวติดตั้ง (.exe)

เมื่อเปิดครั้งแรกคุณจะตั้งวลีรหัสผ่าน — แอปจะถูกล็อกจนกว่าคุณจะป้อน

ตรวจสอบว่าไฟล์ที่ดาวน์โหลดตรงกับที่เราเผยแพร่ทุกประการ

ทุกรุ่นที่ออกจะระบุ SHA-256 ของแต่ละไฟล์ เรียกใช้คำสั่งนี้ใน PowerShell กับไฟล์ที่คุณดาวน์โหลดแล้วเปรียบเทียบ — หากสองสตริงตรงกัน แสดงว่าไฟล์มาถึงอย่างสมบูรณ์และไม่ถูกแก้ไข

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

แฮชที่เผยแพร่สำหรับ รุ่นนี้:

release-manifest.json

ข้อมูลของคุณอยู่บนอุปกรณ์ของคุณ เราไม่เคยเห็นมัน ดูที่ นโยบายความเป็นส่วนตัว.
