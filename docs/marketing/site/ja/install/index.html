🧩 ブラウザ拡張機能 v1.0.3

拡張機能をダウンロード（.zip）

ストアに掲載されるまでは、デベロッパーモードで読み込んでください：

  1. ダウンロードをフォルダに解凍します。
  2. chrome://extensions（または edge://extensions）を開きます。
  3. デベロッパーモードをオンにします（右上）。
  4. 「パッケージ化されていない拡張機能を読み込む」をクリック → 解凍したフォルダを選択します。PolyglotFormFill が拡張機能の一覧に表示されます。
  5. 見つけやすいようツールバーに固定しましょう：ブラウザ右上付近のパズルピースアイコン 🧩（拡張機能メニュー）をクリックし、PolyglotFormFill を見つけて、その隣のピン 📌 をクリックします。アイコンがツールバーに表示されます。
  6. そのツールバーの PolyglotFormFill アイコンをクリック → パスフレーズを設定します（またはパスキーで解錠）。
  7. ポップアップの「あなたの情報」で、各項目（例：full_name、email、phone）とその値を入力し、「項目を保存」をクリックします。これらはお使いのデバイス上で暗号化して保存されます。その後フォームを開き、「このページを記入」をクリックします。

読み込んだ直後にツールバーアイコンが見当たりませんか？それは正常です——Chrome は固定するまで（手順 5）、新しい拡張機能を 🧩 パズルピースメニューの中に隠します。Firefox：about:debugging →「一時的なアドオンを読み込む」を使い、ツールバーのオーバーフローから固定してください。

まもなく提供 · 最もスムーズなデスクトップインストール

⌨️ Windows：winget でインストール

Windows には組み込みのパッケージマネージャーがあります。私たちの掲載が承認されれば、デスクトップアプリはひとつのコマンドでインストールできます——ダウンロードの確認も、クリックして通過すべき警告もありません：

winget install SubramanyaMysore.PolyglotFormFill

winget はインストーラーを取得し、実行前に公開されたチェックサムと照合します。まだ有効ではありません——掲載は Windows Package Manager リポジトリで審査待ちです。それまでは、下記の直接ダウンロードをご利用ください。

🖥️ Windows デスクトップアプリ——直接ダウンロード v1.0.2

Windows が表示する内容と、その理由。 私たちはまだコード署名証明書を購入していません——それは登録済みの企業に販売され、年に数百ドルかかるため、あなたにその費用を請求するよりは先送りにしたいと考えています。そのため Windows はまだ発行元名を認識せず、インストーラーを初めて実行するときにこの青いボックスを表示します：
Windows によって PC が保護されました Microsoft Defender SmartScreen は認識されないアプリの起動を阻止しました。
このメッセージは「この発行元を以前に見たことがない」という意味であり——ファイルに何か問題があるという意味ではありません。続行するには：
  1. 「詳細情報」をクリックします（青いボックス内の小さなリンク）。
  2. 「実行」をクリックします。
これは初回インストール時に一度だけ表示されます。完全に避けたいですか？上記の winget、または影響を受けないブラウザ拡張機能をお使いください。
インストーラーをダウンロード（.exe）

初回起動時にパスフレーズを設定します——入力するまでアプリはロックされています。

ダウンロードが私たちの公開したものと完全に一致するか確認

各リリースはファイルごとの SHA-256 を掲載しています。ダウンロードしたファイルに対して PowerShell で以下を実行し、比較してください——二つの文字列が一致すれば、ファイルは無傷・改変なしで届いています。

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256
