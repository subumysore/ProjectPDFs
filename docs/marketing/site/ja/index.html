PolyglotFormFill は、ある言語のフォームを読み取り、別の言語のあなたのデータから記入します——PDF、Word、Excel、そしてウェブフォームに対応。すべてはお使いのデバイス上で動作し、私たちがあなたのデータを見ることはありません。送信すると、あなたが選んだ宛先へ直接届きます——決して私たちを経由しません。

目玉となる機能

記入できない PDF を、実際に記入できるフォームに変える

フォーム項目のないフラットな PDF——あるいはその写真やスキャンでさえ——が、数秒で本物の記入可能なフォームになります。「印刷して手書きして再スキャン」は不要。どこかのウェブサイトにアップロードして処理する必要もありません。

🧩
記入不可 → 記入可能

あらゆるフラット PDF、スキャン、写真が編集可能なフォームに

記入欄のない PDF、あるいは紙のフォームの写真にさえ向けてください。デバイス上の OCR がレイアウトを読み取り、各項目の位置を見つけ、そこに本物のフォーム項目を配置し、あなたの保管庫から記入します——すべてお使いのマシン上で行われ、何もアップロードされません。その後、きれいに記入された PDF をエクスポートできます。

🔒

常にデバイス上で

OCR、翻訳、記入、署名はローカルで動作します。あなたのデータが私たちや誰かに送られることはありません。

🌍

多言語での記入

どの言語のフォームでも、別のどの言語のデータからでも入力できます — 日本語の情報から英語やヒンディー語のフォームへ、その逆も。翻訳はすべて端末上で行われます。

📄

Word・Excel にも対応

.docx と .xlsx のフォームに記入——名前付き項目でもフラットなラベルでも——PDF にエクスポートできます。

🧠

学習する保管庫

新しい項目に一度答えれば記憶されます——お使いのデバイス上で暗号化して——次回のために。

✍️

信頼できる署名

委任不可・デバイスに紐づいた署名で、検証可能な来歴を備えます。誰もあなたに代わって署名できません。

🔑

パスフレーズは、あなたの端末だけに

パスフレーズは端末から出ません。保管庫を開くときも、あなた自身の端末の中だけで照合されます — どこにも送信されず、誰にも保存されません。私たちも保存しません。ハードウェアがお好みなら、パスキー（WebAuthn）で解錠できます。

🔗

デスクトップ + ブラウザ

拡張機能がウェブフォームに記入し、デスクトップアプリが堅牢な信頼の基点としてあなたの鍵を保持します。

対象ユーザー

言語や国境を越えてフォームを記入する、すべての人のために

特に恩恵を受けるのは三つのグループ——そしてそのいずれもが、データを自分自身のデバイスに保ち続けます。

🛂

移民・移住支援エージェンシー

スキャンしたビザ、在留、定住の PDF を、デバイス上の OCR で記入可能なフォームに変え、一枚の文書もマシンから出すことなく、クライアントの言語で仕上げます。保存したプロファイル一つで、次のフォームも数秒で記入できます。

💼

国境を越えるフリーランサー・小規模事業者

税務、銀行、オンボーディングのフォームは、しばしばあなたの言語ではない言語で届きます。それらを、あなたのデバイス上の AES-256 保管庫に保持された自分の情報から記入し、きれいな PDF をエクスポート——私たちや第三者を一切経由しません。

🛡️

プライバシー重視・暗号コミュニティ

あらゆる工程がテレメトリなしでローカルに動作し、保管庫は鍵が決して保存されないハードウェアパスキー（WebAuthn）で解錠されます。アカウントなし、クラウドなし、トラッキングなし——あなたのデータは、あなたが管理するデバイスにとどまります。

多言語の世界のために

あなたのデータはあなたの言語で。フォームは相手の言語で。

政府や機関はある言語でフォームを発行し、人々の情報は別の言語で保管されています。PolyglotFormFill はその隔たりを端末上で埋めます — どの言語のフォームでも読み取って入力し、約200言語のあいだで、どの言語からどの言語へでも翻訳します。
