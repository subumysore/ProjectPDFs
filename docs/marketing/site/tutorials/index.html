Good to know

Keep & move your data

  1. Save your details (do this once): open the popup → Backup / transfer → type a passphrase → Export encrypted → choose where to save the .ppfvault file. That file is your safety net.
  2. Move to another device / restore: type the same passphrase → Import file… → pick your .ppfvault. Everything comes back — the same file works in the extension and the desktop app.
  3. Fill a PDF: open the PDF → Fill this page → the completed PDF opens and auto-downloads as <original>-filled.pdf. (Browsers can’t edit the on-screen PDF, so you get the finished copy.)
  4. Fill a web form: on any normal web form, Fill this page fills the boxes live, on screen.
  5. Updating without losing data: when a new version ships, replace the files in the same folder and click ↻ Reload — never “Remove.” Your vault stays put.
