  2. chrome://extensions کھولیں (یا edge://extensions)۔
  3. ڈیولپر موڈ آن کریں (اوپر دائیں جانب)۔
  4. Load unpacked پر کلک کریں ← ان زپ کیا ہوا فولڈر منتخب کریں۔ PolyglotFormFill اب آپ کی ایکسٹینشنز کی فہرست میں ظاہر ہوگا۔
  5. اسے ٹول بار پر پن کریں تاکہ آپ اسے تلاش کر سکیں: براؤزر کے اوپر دائیں کونے کے قریب پہیلی کے ٹکڑے کا آئیکن 🧩 (یعنی ایکسٹینشنز مینو) پر کلک کریں، PolyglotFormFill تلاش کریں، اور اس کے ساتھ پن 📌 پر کلک کریں۔ اس کا آئیکن اب آپ کے ٹول بار پر آ جائے گا۔
  6. اُس PolyglotFormFill ٹول بار آئیکن پر کلک کریں ← ایک پاس فریز مقرر کریں (یا پاس کی سے کھولیں)۔
  7. پاپ اپ میں «آپ کی تفصیلات» کے تحت، ہر فیلڈ (مثلاً full_name، email، phone) اور اس کی قدر لکھیں، پھر Save field کریں۔ یہ آپ کے آلے پر خفیہ کر کے محفوظ کی جاتی ہیں۔ پھر کوئی فارم کھولیں اور Fill this page پر کلک کریں۔

⌨️ Windows: winget سے انسٹال کریں

Windows میں ایک بلٹ اِن پیکج مینیجر ہے۔ جیسے ہی ہماری فہرست منظور ہو جائے، ڈیسک ٹاپ ایپ ایک ہی کمانڈ سے انسٹال ہو جاتی ہے — کوئی ڈاؤن لوڈ پرامپٹ نہیں، اور کوئی وارننگ نہیں جس سے گزرنا پڑے:

winget install SubramanyaMysore.PolyglotFormFill

winget انسٹالر لاتا ہے اور اسے چلانے سے پہلے شائع شدہ چیک سم کے مقابلے میں جانچتا ہے۔ ابھی فعال نہیں — فہرست Windows Package Manager ریپازٹری میں جائزے کی منتظر ہے۔ تب تک، نیچے دیا گیا براہِ راست ڈاؤن لوڈ استعمال کریں۔

🖥️ Windows ڈیسک ٹاپ ایپ — براہِ راست ڈاؤن لوڈ v1.0.0

Windows آپ کو کیا دکھائے گا، اور کیوں۔ ہم نے ابھی کوڈ سائننگ سرٹیفکیٹ نہیں خریدا — یہ رجسٹرڈ کمپنیوں کو فروخت کیے جاتے ہیں اور سالانہ چند سو ڈالر لاگت آتی ہے، اور ہم اسے مؤخر کرنا پسند کریں گے بجائے اس کے کہ آپ سے اس کی وصولی کریں۔ اسی لیے Windows ابھی پبلشر کا نام نہیں پہچانتا، اور جب آپ پہلی بار انسٹالر چلاتے ہیں تو یہ نیلا باکس دکھاتا ہے:
Windows نے آپ کے PC کی حفاظت کی Microsoft Defender SmartScreen نے ایک ناشناختہ ایپ کو شروع ہونے سے روک دیا۔
اُس پیغام کا مطلب ہے «میں نے یہ پبلشر پہلے نہیں دیکھا» — یہ نہیں کہ فائل میں کوئی خرابی ہے۔ جاری رکھنے کے لیے:
  1. More info پر کلک کریں (نیلے باکس کے اندر ایک چھوٹا لنک)۔
  2. Run anyway پر کلک کریں۔
یہ ایک بار ظاہر ہوتا ہے، پہلی انسٹال پر۔ اسے مکمل طور پر ٹالنا چاہتے ہیں؟ اوپر دیا گیا winget استعمال کریں، یا براؤزر ایکسٹینشن، جو اس سے متاثر نہیں ہوتی۔

جانچیں کہ ڈاؤن لوڈ بالکل وہی ہے جو ہم نے شائع کیا

ہر ریلیز ہر فائل کا SHA-256 درج کرتی ہے۔ جو فائل آپ نے ڈاؤن لوڈ کی اُس پر PowerShell میں یہ چلائیں اور موازنہ کریں — اگر دونوں سٹرنگز مماثل ہوں، تو فائل سالم اور بلا تبدیلی پہنچی ہے۔

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

release-manifest.json
