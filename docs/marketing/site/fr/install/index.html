🧩 Extension de navigateur v1.0.3

Télécharger l'extension (.zip)

En attendant qu'elle soit sur les stores, chargez-la en mode développeur :

  1. Décompressez le téléchargement dans un dossier.
  2. Ouvrez chrome://extensions (ou edge://extensions).
  3. Activez le Mode développeur (en haut à droite).
  4. Cliquez sur Charger l'extension non empaquetée → sélectionnez le dossier décompressé. PolyglotFormFill apparaît maintenant dans votre liste d'extensions.
  5. Épinglez-la à la barre d'outils pour la retrouver : cliquez sur l'icône en forme de pièce de puzzle 🧩 près du coin supérieur droit du navigateur (c'est le menu Extensions), trouvez PolyglotFormFill et cliquez sur l'épingle 📌 à côté. Son icône est désormais sur votre barre d'outils.
  6. Cliquez sur cette icône PolyglotFormFill dans la barre d'outils → définissez une phrase secrète (ou déverrouillez avec une clé d'accès).
  7. Sous « Vos informations » dans la fenêtre contextuelle, saisissez chaque champ (p. ex. full_name, email, phone) et sa valeur, puis Enregistrer le champ. Ils sont stockés chiffrés sur votre appareil. Ouvrez ensuite un formulaire et cliquez sur Remplir cette page.

Vous ne voyez pas d'icône dans la barre d'outils juste après le chargement ? C'est normal — Chrome masque les nouvelles extensions derrière le menu de la pièce de puzzle 🧩 jusqu'à ce que vous les épingliez (étape 5). Firefox : utilisez about:debugging → « Charger un module temporaire », puis épinglez depuis le débordement de la barre d'outils.

⌨️ Windows : installer avec winget

Windows dispose d'un gestionnaire de paquets intégré. Une fois notre référencement approuvé, l'application de bureau s'installe avec une seule commande — sans invite de téléchargement et sans avertissement à valider :

winget install SubramanyaMysore.PolyglotFormFill

winget récupère l'installateur et le vérifie par rapport à une somme de contrôle publiée avant de l'exécuter. Pas encore disponible — le référencement attend une revue dans le dépôt du Windows Package Manager. En attendant, utilisez le téléchargement direct ci-dessous.

Télécharger l'installateur (.exe)

Au premier lancement, vous définirez une phrase secrète — l'application est verrouillée tant que vous ne l'avez pas saisie.

Vérifiez que le téléchargement correspond exactement à ce que nous avons publié

Chaque version indique le SHA-256 de chaque fichier. Exécutez ceci dans PowerShell sur le fichier que vous avez téléchargé et comparez — si les deux chaînes correspondent, le fichier est arrivé intact et inaltéré.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256
