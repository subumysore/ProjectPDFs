Comece com a extensão do navegador — é o caminho mais rápido e faz o trabalho principal. O aplicativo desktop adiciona assinatura, histórico e trabalho offline.

Comece aqui · mais fácil

🧩 Extensão do navegador v1.0.3

Baixar extensão (.zip)

Até estar nas lojas, carregue-a no modo de desenvolvedor:

  1. Descompacte o download em uma pasta.
  2. Abra chrome://extensions (ou edge://extensions).
  3. Ative o Modo de desenvolvedor (canto superior direito).
  4. Clique em Carregar sem compactação → selecione a pasta descompactada. O PolyglotFormFill agora aparece na sua lista de extensões.
  5. Fixe-a na barra de ferramentas para poder encontrá-la: clique no ícone de peça de quebra-cabeça 🧩 perto do canto superior direito do navegador (esse é o menu de Extensões), encontre o PolyglotFormFill e clique no alfinete 📌 ao lado dele. O ícone agora fica na sua barra de ferramentas.
  6. Clique nesse ícone do PolyglotFormFill na barra de ferramentas → defina uma frase-senha (ou desbloqueie com uma chave de acesso).
  7. Em "Seus dados" no pop-up, digite cada campo (por exemplo, full_name, email, phone) e seu valor, depois Salvar campo. Eles são armazenados criptografados no seu dispositivo. Depois abra um formulário e clique em Preencher esta página.

Não vê um ícone na barra de ferramentas logo após carregar? Isso é normal — o Chrome oculta novas extensões atrás do menu de peça de quebra-cabeça 🧩 até você fixá-las (passo 5). Firefox: use about:debugging → "Carregar extensão temporária", depois fixe pelo excesso da barra de ferramentas.

Em breve · a instalação de desktop mais tranquila

⌨️ Windows: instalar com winget

O Windows tem um gerenciador de pacotes integrado. Assim que nossa listagem for aprovada, o aplicativo desktop se instala com um único comando — sem aviso de download e sem alerta para clicar:

winget install SubramanyaMysore.PolyglotFormFill

O winget busca o instalador e o verifica contra uma soma de verificação publicada antes de executá-lo. Ainda não disponível — a listagem aguarda revisão no repositório do Windows Package Manager. Até lá, use o download direto abaixo.

🖥️ Aplicativo desktop do Windows — download direto v1.0.1

O que o Windows vai mostrar, e por quê. Ainda não compramos um certificado de assinatura de código — eles são vendidos a empresas registradas e custam algumas centenas de dólares por ano, e preferimos adiar isso a cobrá-lo de você. Por isso o Windows ainda não reconhece o nome do editor e mostra esta caixa azul na primeira vez que você executa o instalador:
O Windows protegeu seu PC O Microsoft Defender SmartScreen impediu que um aplicativo não reconhecido fosse iniciado.
Essa mensagem significa "nunca vi este editor antes" — não que haja algo errado com o arquivo. Para continuar:
  1. Clique em Mais informações (o pequeno link dentro da caixa azul).
  2. Clique em Executar assim mesmo.
Ela aparece uma vez, na primeira instalação. Prefere evitá-la totalmente? Use o winget acima, ou a extensão do navegador, que não é afetada.
Baixar instalador (.exe)

No primeiro início você definirá uma frase-senha — o aplicativo fica bloqueado até você inseri-la.

Verifique se o download é exatamente o que publicamos

Cada versão lista o SHA-256 de cada arquivo. Execute isto no PowerShell no arquivo que você baixou e compare — se as duas cadeias coincidirem, o arquivo chegou intacto e inalterado.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256
