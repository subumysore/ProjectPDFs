🧩 ബ്രൗസർ എക്സ്റ്റൻഷൻ v1.0.4

എക്സ്റ്റൻഷൻ ഡൗൺലോഡ് ചെയ്യുക (.zip)

ഇത് സ്റ്റോറുകളിൽ വരുന്നതുവരെ, ഡെവലപ്പർ മോഡിൽ ലോഡ് ചെയ്യുക:

  1. ഡൗൺലോഡ് ഒരു ഫോൾഡറിലേക്ക് അൺസിപ്പ് ചെയ്യുക.
  2. chrome://extensions (അല്ലെങ്കിൽ edge://extensions) തുറക്കുക.
  3. Developer mode ഓണാക്കുക (മുകളിൽ-വലത്).
  4. Load unpacked ക്ലിക്ക് ചെയ്യുക → അൺസിപ്പ് ചെയ്ത ഫോൾഡർ തിരഞ്ഞെടുക്കുക. PolyglotFormFill ഇപ്പോൾ നിങ്ങളുടെ എക്സ്റ്റൻഷനുകളുടെ പട്ടികയിൽ ദൃശ്യമാകുന്നു.
  5. നിങ്ങൾക്ക് കണ്ടെത്താൻ കഴിയുന്ന വിധം അത് ടൂൾബാറിലേക്ക് പിൻ ചെയ്യുക: ബ്രൗസറിന്റെ മുകളിൽ-വലതുഭാഗത്തുള്ള പസിൽ-പീസ് ഐക്കൺ 🧩 ക്ലിക്ക് ചെയ്യുക (അതാണ് എക്സ്റ്റൻഷനുകൾ മെനു), PolyglotFormFill കണ്ടെത്തി, അതിന് അടുത്തുള്ള പിൻ 📌 ക്ലിക്ക് ചെയ്യുക. അതിന്റെ ഐക്കൺ ഇപ്പോൾ നിങ്ങളുടെ ടൂൾബാറിൽ ഇരിക്കുന്നു.
  6. ആ PolyglotFormFill ടൂൾബാർ ഐക്കൺ ക്ലിക്ക് ചെയ്യുക → ഒരു പാസ്‌ഫ്രെയ്‌സ് സജ്ജീകരിക്കുക (അല്ലെങ്കിൽ ഒരു പാസ്‌കീ ഉപയോഗിച്ച് അൺലോക്ക് ചെയ്യുക).
  7. പോപ്പപ്പിലെ “നിങ്ങളുടെ വിവരങ്ങൾ” എന്നതിന് കീഴിൽ, ഓരോ ഫീൽഡും (ഉദാ. full_name, email, phone) അതിന്റെ മൂല്യവും ടൈപ്പ് ചെയ്ത്, തുടർന്ന് Save field അമർത്തുക. ഇവ നിങ്ങളുടെ ഉപകരണത്തിൽ എൻക്രിപ്റ്റ് ചെയ്ത് സംഭരിക്കുന്നു. തുടർന്ന് ഒരു ഫോം തുറന്ന് Fill this page ക്ലിക്ക് ചെയ്യുക.

ലോഡ് ചെയ്ത ഉടനെ ടൂൾബാർ ഐക്കൺ കാണുന്നില്ലേ? അത് സാധാരണമാണ് — നിങ്ങൾ അവ പിൻ ചെയ്യുന്നതുവരെ (ഘട്ടം 5) Chrome പുതിയ എക്സ്റ്റൻഷനുകൾ 🧩 പസിൽ-പീസ് മെനുവിന് പിന്നിൽ മറയ്ക്കുന്നു. Firefox: about:debugging → “Load Temporary Add-on” ഉപയോഗിക്കുക, തുടർന്ന് ടൂൾബാർ ഓവർഫ്ലോയിൽ നിന്ന് പിൻ ചെയ്യുക.

ഉടൻ വരുന്നു · ഏറ്റവും സുഗമമായ ഡെസ്ക്ടോപ്പ് ഇൻസ്റ്റാൾ

⌨️ Windows: winget ഉപയോഗിച്ച് ഇൻസ്റ്റാൾ ചെയ്യുക

Windows-ന് ഒരു ബിൽറ്റ്-ഇൻ പാക്കേജ് മാനേജർ ഉണ്ട്. ഞങ്ങളുടെ ലിസ്റ്റിംഗ് അംഗീകരിച്ചാൽ, ഡെസ്ക്ടോപ്പ് ആപ്പ് ഒരൊറ്റ കമാൻഡ് ഉപയോഗിച്ച് ഇൻസ്റ്റാൾ ചെയ്യുന്നു — ഡൗൺലോഡ് പ്രോംപ്റ്റ് ഇല്ല, ക്ലിക്ക് ചെയ്യേണ്ട മുന്നറിയിപ്പ് ഇല്ല:

winget install SubramanyaMysore.PolyglotFormFill

winget ഇൻസ്റ്റാളർ കൊണ്ടുവന്ന്, അത് പ്രവർത്തിപ്പിക്കുന്നതിന് മുമ്പ് പ്രസിദ്ധീകരിച്ച ചെക്ക്‌സമ്മുമായി പരിശോധിക്കുന്നു. ഇതുവരെ ലൈവ് അല്ല — ലിസ്റ്റിംഗ് Windows Package Manager റിപ്പോസിറ്ററിയിൽ അവലോകനത്തിനായി കാത്തിരിക്കുന്നു. അതുവരെ, താഴെയുള്ള നേരിട്ടുള്ള ഡൗൺലോഡ് ഉപയോഗിക്കുക.

ഇൻസ്റ്റാളർ ഡൗൺലോഡ് ചെയ്യുക (.exe)

ആദ്യ ലോഞ്ചിൽ നിങ്ങൾ ഒരു പാസ്‌ഫ്രെയ്‌സ് സജ്ജീകരിക്കും — നിങ്ങൾ അത് നൽകുന്നതുവരെ ആപ്പ് ലോക്ക് ചെയ്തിരിക്കും.

ഞങ്ങൾ പ്രസിദ്ധീകരിച്ചത് കൃത്യമായി ഇതാണോ എന്ന് ഡൗൺലോഡ് പരിശോധിക്കുക

ഓരോ റിലീസും ഓരോ ഫയലിന്റെയും SHA-256 ലിസ്റ്റ് ചെയ്യുന്നു. നിങ്ങൾ ഡൗൺലോഡ് ചെയ്ത ഫയലിൽ PowerShell-ൽ ഇത് പ്രവർത്തിപ്പിച്ച് താരതമ്യം ചെയ്യുക — രണ്ട് സ്ട്രിംഗുകളും പൊരുത്തപ്പെട്ടാൽ, ഫയൽ കേടുകൂടാതെ, മാറ്റം വരുത്താതെ എത്തിയിരിക്കുന്നു.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

പ്രസിദ്ധീകരിച്ച ഹാഷുകൾ ഈ റിലീസ്:

release-manifest.json

നിങ്ങളുടെ ഡാറ്റ നിങ്ങളുടെ ഉപകരണത്തിൽ തന്നെ നിലനിൽക്കുന്നു; ഞങ്ങൾ അത് ഒരിക്കലും കാണുന്നില്ല. കാണുക സ്വകാര്യതാ നയം.
