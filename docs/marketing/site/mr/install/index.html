🧩 ब्राउझर एक्स्टेंशन v1.0.1

एक्स्टेंशन डाउनलोड करा (.zip)

ते स्टोअरवर येईपर्यंत, ते डेव्हलपर मोडमध्ये लोड करा:

  1. डाउनलोड एका फोल्डरमध्ये अनझिप करा.
  2. chrome://extensions (किंवा edge://extensions) उघडा.
  3. Developer mode चालू करा (वर-उजवीकडे).
  4. Load unpacked वर क्लिक करा → अनझिप केलेले फोल्डर निवडा. PolyglotFormFill आता तुमच्या एक्स्टेंशन यादीत दिसते.
  5. ते टूलबारवर पिन करा जेणेकरून तुम्हाला ते सापडेल: ब्राउझरच्या वर-उजवीकडे कोडे-तुकड्याच्या आयकॉन 🧩 वर क्लिक करा (तो Extensions मेनू आहे), PolyglotFormFill शोधा आणि त्याच्या शेजारील पिन 📌 वर क्लिक करा. त्याचा आयकॉन आता तुमच्या टूलबारवर राहतो.
  6. त्या PolyglotFormFill टूलबार आयकॉनवर क्लिक करा → पासफ्रेज सेट करा (किंवा पासकी ने अनलॉक करा).
  7. पॉपअपमधील "Your details" खाली, प्रत्येक फील्ड (उदा. full_name, email, phone) आणि त्याचे मूल्य टाइप करा, नंतर Save field करा. हे तुमच्या डिव्हाइसवर एन्क्रिप्ट करून साठवले जातात. नंतर एक फॉर्म उघडा आणि Fill this page वर क्लिक करा.

लोड केल्यानंतर लगेच टूलबार आयकॉन दिसत नाही? हे सामान्य आहे — तुम्ही पिन करेपर्यंत (पायरी 5) Chrome नवीन एक्स्टेंशन 🧩 कोडे-तुकड्याच्या मेनूमागे लपवते. Firefox: about:debugging → "Load Temporary Add-on" वापरा, नंतर टूलबार ओव्हरफ्लोमधून पिन करा.

⌨️ Windows: winget ने इन्स्टॉल करा

Windows मध्ये अंगभूत पॅकेज मॅनेजर आहे. आमची सूची मंजूर झाल्यावर, डेस्कटॉप अॅप एकाच कमांडने इन्स्टॉल होते — कोणताही डाउनलोड सूचना नाही, आणि क्लिक करून पार करण्याची कोणतीही चेतावणी नाही:

winget install SubramanyaMysore.PolyglotFormFill

winget इन्स्टॉलर आणतो आणि तो चालवण्यापूर्वी प्रकाशित चेकसमशी तपासतो. अद्याप लाइव्ह नाही — सूची Windows Package Manager रिपॉझिटरीमध्ये पुनरावलोकनाच्या प्रतीक्षेत आहे. तोपर्यंत, खालील थेट डाउनलोड वापरा.

🖥️ Windows डेस्कटॉप अॅप — थेट डाउनलोड v1.0.0

Windows तुम्हाला काय दाखवेल, आणि का. आम्ही अद्याप कोड-स्वाक्षरी प्रमाणपत्र विकत घेतलेले नाही — ती नोंदणीकृत कंपन्यांना विकली जातात आणि वर्षाला काहीशे डॉलर खर्च येतो, आणि त्यासाठी तुमच्याकडून शुल्क घेण्याऐवजी आम्ही ते पुढे ढकलणे पसंत करू. त्यामुळे Windows अद्याप प्रकाशकाचे नाव ओळखत नाही, आणि तुम्ही पहिल्यांदा इन्स्टॉलर चालवता तेव्हा हा निळा बॉक्स दाखवते:
Windows ने तुमच्या PC चे संरक्षण केले Microsoft Defender SmartScreen ने एका अनोळखी अॅपला सुरू होण्यापासून रोखले.
त्या संदेशाचा अर्थ "मी हा प्रकाशक याआधी पाहिलेला नाही" — फाइलमध्ये काही चूक आहे असे नाही. पुढे जाण्यासाठी:
  1. More info वर क्लिक करा (निळ्या बॉक्समधील लहान दुवा).
  2. Run anyway वर क्लिक करा.
हे एकदाच, पहिल्या इन्स्टॉलवेळी दिसते. ते पूर्णपणे टाळायचे आहे? वरील winget वापरा, किंवा ब्राउझर एक्स्टेंशन, जे यामुळे प्रभावित होत नाही.
इन्स्टॉलर डाउनलोड करा (.exe)

पहिल्यांदा सुरू करताना तुम्ही पासफ्रेज सेट कराल — तुम्ही तो प्रविष्ट करेपर्यंत अॅप लॉक असते.

डाउनलोड आम्ही प्रकाशित केले तेच आहे का ते तपासा

प्रत्येक रिलीज प्रत्येक फाइलचा SHA-256 सूचीबद्ध करते. तुम्ही डाउनलोड केलेल्या फाइलवर हे PowerShell मध्ये चालवा आणि तुलना करा — जर दोन्ही स्ट्रिंग जुळल्या, तर फाइल अखंड आणि अपरिवर्तित पोहोचली आहे.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

यासाठी प्रकाशित हॅश ही रिलीज:

release-manifest.json

तुमचा डेटा तुमच्या डिव्हाइसवरच राहतो; आम्ही तो कधीही पाहत नाही. पाहा गोपनीयता धोरण.
