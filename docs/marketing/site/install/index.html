Early builds. The Chrome Web Store / Edge / Firefox one-click installs are coming; until then, use the direct downloads below.

🖥️ Windows desktop app

Download installer (.exe)   or MSI
Heads-up: this build is unsigned, so Windows SmartScreen will say “Windows protected your PC / unknown publisher.” Click More info → Run anyway. (A signed release removes this warning.)

Hosted on Oracle Cloud Object Storage. On first launch you’ll set a passphrase — the app is locked until you enter it.

🧩 Browser extension

Download extension (.zip)

Until it’s on the stores, load it in developer mode:

  1. Unzip the download to a folder.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode (top-right).
  4. Click Load unpacked → select the unzipped folder.
  5. Click the toolbar icon → set a passphrase (or unlock with a passkey) → fill forms.

Firefox: use about:debugging → “Load Temporary Add-on”.

Your data stays on your device; we never see it. See the privacy policy.
