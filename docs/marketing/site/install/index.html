Start here · easiest

🧩 Browser extension v0.2.16

Download extension (.zip)

Until it’s on the stores, load it in developer mode:

  1. Unzip the download to a folder.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode (top-right).
  4. Click Load unpacked → select the unzipped folder. PolyglotFormFill now appears in your extensions list.
  5. Pin it to the toolbar so you can find it: click the puzzle-piece icon 🧩 near the top-right of the browser (that’s the Extensions menu), find PolyglotFormFill, and click the pin 📌 next to it. Its icon now sits on your toolbar.
  6. Click that PolyglotFormFill toolbar icon → set a passphrase (or unlock with a passkey).
  7. Under “Your details” in the popup, type each field (e.g. full_name, email, phone) and its value, then Save field. These are stored encrypted on your device. Then open a form and click Fill this page.

Don’t see a toolbar icon right after loading? That’s normal — Chrome hides new extensions behind the 🧩 puzzle-piece menu until you pin them (step 6). Firefox: use about:debugging → “Load Temporary Add-on”, then pin from the toolbar overflow.

Recommended for the desktop app

⌨️ Windows: install with winget

Windows has a built-in package manager. One command, no download prompts:

winget install PolyglotFormFill

Open Terminal or PowerShell from the Start menu and paste that line. winget fetches the installer and checks it against a published checksum for you.

🖥️ Windows desktop app — direct download v1.0.0

What Windows will show you, and why. We haven’t bought a code-signing certificate yet — they’re sold to registered companies and cost a few hundred dollars a year, and we’d rather put that off than charge you for it. Windows therefore doesn’t recognise the publisher name yet, and shows this blue box the first time you run the installer:
Windows protected your PC Microsoft Defender SmartScreen prevented an unrecognised app from starting.
That message means “I haven’t seen this publisher before” — not that anything is wrong with the file. To continue:
  1. Click More info (small link inside the blue box).
  2. Click Run anyway.
It appears once, on first install. Prefer to avoid it entirely? Use winget above, or the browser extension, which is unaffected.

Check the download is exactly what we published

Every release lists the SHA-256 of each file. Run this in PowerShell on the file you downloaded and compare — if the two strings match, the file arrived intact and unaltered.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256
