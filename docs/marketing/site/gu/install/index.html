🧩 બ્રાઉઝર એક્સટેન્શન v1.0.11

એક્સટેન્શન ડાઉનલોડ કરો (.zip)

તે સ્ટોર પર આવે ત્યાં સુધી, તેને ડેવલપર મોડમાં લોડ કરો:

  1. ડાઉનલોડને એક ફોલ્ડરમાં અનઝિપ કરો.
  2. chrome://extensions (અથવા edge://extensions) ખોલો.
  3. Developer mode ચાલુ કરો (ઉપર-જમણે).
  4. Load unpacked પર ક્લિક કરો → અનઝિપ કરેલું ફોલ્ડર પસંદ કરો. PolyglotFormFill હવે તમારી એક્સટેન્શન યાદીમાં દેખાય છે.
  5. તેને ટૂલબાર પર પિન કરો જેથી તમે તેને શોધી શકો: બ્રાઉઝરના ઉપર-જમણી બાજુ કોયડા-ટુકડાના આઇકન 🧩 પર ક્લિક કરો (તે Extensions મેનૂ છે), PolyglotFormFill શોધો અને તેની બાજુના પિન 📌 પર ક્લિક કરો. તેનું આઇકન હવે તમારા ટૂલબાર પર રહે છે.
  6. તે PolyglotFormFill ટૂલબાર આઇકન પર ક્લિક કરો → પાસફ્રેઝ સેટ કરો (અથવા પાસકી થી અનલૉક કરો).
  7. પૉપઅપમાં "Your details" હેઠળ, દરેક ફીલ્ડ (દા.ત. full_name, email, phone) અને તેનું મૂલ્ય ટાઇપ કરો, પછી Save field કરો. આ તમારા ડિવાઇસ પર એન્ક્રિપ્ટ કરીને સંગ્રહાય છે. પછી એક ફોર્મ ખોલો અને Fill this page પર ક્લિક કરો.

લોડ કર્યા પછી તરત જ ટૂલબાર આઇકન દેખાતું નથી? આ સામાન્ય છે — તમે પિન કરો ત્યાં સુધી (પગલું 5) Chrome નવા એક્સટેન્શનને 🧩 કોયડા-ટુકડાના મેનૂ પાછળ છુપાવે છે. Firefox: about:debugging → "Load Temporary Add-on" વાપરો, પછી ટૂલબાર ઓવરફ્લોમાંથી પિન કરો.

ટૂંક સમયમાં આવી રહ્યું છે · સૌથી સરળ ડેસ્કટૉપ ઇન્સ્ટૉલ

⌨️ Windows: winget થી ઇન્સ્ટૉલ કરો

Windows માં એક બિલ્ટ-ઇન પૅકેજ મેનેજર છે. અમારી લિસ્ટિંગ મંજૂર થયા પછી, ડેસ્કટૉપ એપ એક જ કમાન્ડથી ઇન્સ્ટૉલ થાય છે — કોઈ ડાઉનલોડ સૂચના નહીં, અને ક્લિક કરીને પસાર થવાની કોઈ ચેતવણી નહીં:

winget install SubramanyaMysore.PolyglotFormFill

winget ઇન્સ્ટૉલર લાવે છે અને ચલાવતા પહેલા તેને પ્રકાશિત ચેકસમ સામે તપાસે છે. હજુ લાઇવ નથી — લિસ્ટિંગ Windows Package Manager રિપોઝિટરીમાં સમીક્ષાની રાહ જોઈ રહી છે. ત્યાં સુધી, નીચેનું સીધું ડાઉનલોડ વાપરો.

ઇન્સ્ટૉલર ડાઉનલોડ કરો (.exe)

પ્રથમ વખત શરૂ કરતી વખતે તમે પાસફ્રેઝ સેટ કરશો — તમે તે દાખલ ન કરો ત્યાં સુધી એપ લૉક રહે છે.

ડાઉનલોડ બરાબર તે જ છે જે અમે પ્રકાશિત કર્યું છે તે તપાસો

દરેક રિલીઝ દરેક ફાઇલનો SHA-256 સૂચિબદ્ધ કરે છે. તમે ડાઉનલોડ કરેલી ફાઇલ પર આ PowerShell માં ચલાવો અને સરખાવો — જો બંને સ્ટ્રિંગ મેળ ખાય, તો ફાઇલ અકબંધ અને અપરિવર્તિત પહોંચી છે.

Get-FileHash .\PolyglotFormFill-Setup.exe -Algorithm SHA256

આ માટે પ્રકાશિત હૅશ આ રિલીઝ:

release-manifest.json

તમારો ડેટા તમારા ડિવાઇસ પર જ રહે છે; અમે તે ક્યારેય જોતા નથી. જુઓ ગોપનીયતા નીતિ.
